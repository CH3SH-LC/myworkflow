# Skill：全书一致性审查 — 整本书的逻辑与设定完整性检查

## 触发场景
- 每完成一个分卷后
- 每完成一个大事件后（可选）
- 定期维护：每写10-15章执行一次
- 写作中感觉"好像哪里不对劲"但说不清楚时

## 必需要素
- 至少已完成一个大事件或5章以上内容（单章不必触发此审查）
- 粗纲、设定文件、角色文件、伏笔记录、时间线 均可查阅
- **指南/风格定位.md**：审查时需对照本书专属的风格要求、禁忌、特殊规则——偏离指南的问题和偏离设定的问题同等对待

## 推荐要素
- 近期章节均已通过「myworkflow:章节审查」

## 前置强制步骤

> **核心原则：指南文件是本书的"宪法"。** 全局审查不仅要查设定一致性和剧情逻辑，更要检查全书的风格统一性——是否偏离了本书的专属风格定位。

1. **读取本书指南文件**：读取 `指南/` 文件夹下所有文件，作为审查基准之一：
   - `指南/风格定位.md` — 全书的情绪基调、文风、节奏是否符合定位？
   - `指南/核心卖点.md` — 全书中是否持续体现差异化定位？
   - `指南/书籍禁忌.md` — 已完成的章节中是否触犯了禁忌？
   - `指南/AI记忆卡片.md` — 关键约束是否被持续遵守？
   - `指南/特殊设定约束.md` — 全书中是否满足所有特殊设定约束？
   → 偏离指南的问题和偏离设定的问题同等对待
   
2. **读取 CLAUDE.md**：了解当前创作状态、已有章节范围、上次审查时间

3. **读取全局对照材料**：读取 `大纲/粗纲.md`、`设定/索引.md`、`进度/伏笔记录.md`、`进度/时间线.md`、`进度/重复性记录.md`，以及主要角色文件

4. **个性化调整审查重点**：
   - 如果指南要求"轻松幽默" → 重点检查是否有连续多章过于沉重
   - 如果指南要求"快节奏" → 重点检查事件节奏是否有拖沓的段落
   - 如果指南有禁止的人物类型/情节 → 检查已完成章节是否越界

## 目标
对已完成的多个章节进行跨章节的全局一致性审查，确保长期设定、人物弧光、力量体系、伏笔、剧情逻辑不出现系统性崩坏。

## 执行流程

## 快速参考

| 疑点 | 查哪个域 |
|------|---------|
| 设定是否前后一致 | 第二步：审查域一（设定全局一致性） |
| 人物是不是"突然变了" | 第二步：审查域二（人物弧光全局一致性） |
| 力量等级是不是通胀了 | 第二步：审查域三（力量体系全局平衡） |
| 有没有忘了填的坑 | 第二步：审查域四（伏笔管理） |
| 事件时间对不对 | 第二步：审查域五（时间线全局检查） |

| 事件节奏和模式有没有重复 | 第二步：审查域七（事件节奏与模式重复） |
| 定位工具 | 第一步：高效准备（索引/伏笔记录/时间线） |

### 第一步：高效准备

**本审查覆盖全书，需要效率策略。先通过 AskUserQuestion 确定审查范围：**

> 使用 `AskUserQuestion` 工具发送以下问题，用户提交后根据回答配置审查策略。

**Q1** | header:"审查范围"

- "聚焦变更": 优先审查上次审查以来新增或修改的章节，旧章节仅抽样（每5-10章抽1章）
- "全面审查": 对全书所有章节进行系统性审查——适合分卷完成或感觉问题较多时

**Q2** | header:"优先聚焦" | multiSelect

- "设定与力量平衡": 感觉世界观/专有名词/战力可能出现了不一致，或担心战力通胀、等级体系崩坏
- "人物弧光": 担心人物行为偏离了设定或弧光不连贯
- "伏笔管理": 感觉有伏笔忘了回收或遗漏
- "时间线与剧情逻辑": 担心时间逻辑有矛盾，或故事因果关系可能有问题（强制情节/机械降神）

> 用户提交后，根据选择的审查范围和优先领域，配置后续审查域的审查深度：
> - **优先聚焦的域**：全量审查（逐章逐项核对）
> - **其余域**：抽样审查——在"聚焦变更"模式下每5-10章抽1章、在"全面审查"模式下每3-5章抽1章
> - 抽样章应均匀分布在各卷/各大事件中，而非集中在同一区域

**快速定位工具：**
   - `设定/索引.md` → 总览所有设定项
   - `进度/伏笔记录.md` → 所有伏笔状态一目了然
   - `进度/时间线.md` → 时间逻辑的总控
**抽样策略**：旧章节每5-10章抽样1章检查关键设定的一致性。

打开以下文件：
- `大纲/粗纲.md`
- `设定/索引.md` 及近期涉及的设定文件
- `角色/` 下所有主要人物设定
- `进度/伏笔记录.md`
- `进度/时间线.md`

### 第二步：逐域审查

---

#### 审查域一：设定全局一致性

- [ ] 近期章节的世界观/设定描述与早期章节是否一致？
  - 重点检查：力量体系的使用（有没有越级/越界）
  - 重点检查：专有名词的使用（同一个概念是否有不同叫法或效果变化）
  - 重点检查：地理/历史描述（有没有前后矛盾的地点/事件）
- [ ] 判定方法：是设定遗漏（需要补设定）还是正文错误（需要改正文）？

---

#### 审查域二：人物弧光全局一致性

- [ ] 每个主要人物的成长轨迹是否连贯？
  - 有没有"突然变了一个人"却没有合理触发的事件？
- [ ] 人物能力增长是否符合设定和弧光规划？
  - 升级节点是否有对应的突破事件？
  - 能力曲线是否平滑（不能从筑基直接跳到元婴）？
- [ ] 人物关系的变化是否有足够的互动支撑？
  - 从敌到友、从陌生到熟悉——中间有没有过渡？

---

#### 审查域三：力量体系全局平衡

- [ ] 全书范围的力量等级有没有通胀？
  - 前期的高手后期是否变成蝼蚁？——如果可以，有合理的世界扩展逻辑吗？
  - 主角升级速度是否远超所有配角？——有合理的外挂/代价支撑吗？
- [ ] 战斗逻辑是否一致？
  - 同局面在不同章节中的处理是否一致？
- [ ] 特殊能力/道具的使用条件和限制是否始终如一？

---

#### 审查域四：伏笔管理

- [ ] 所有"待回收"伏笔中，有没有超出计划回收章节仍未回收的？
- [ ] 有没有关联伏笔被遗漏？（一个伏笔引出另一个，但只回收了第一个）
- [ ] 近期章节有没有无意中制造的新伏笔未在记录中标注？
- [ ] 近期章节有没有实际已回收但未标注的伏笔？

---

#### 审查域五：时间线全局检查

- [ ] 全书的年/月/日是否连贯？
- [ ] 重大事件之间的时间间隔是否合理？
- [ ] 多线叙事时不同的时间线是否同步？
- [ ] 季节/天象/节日描述是否与时间线记录匹配？

---

#### 审查域六：剧情逻辑

**这是不同于设定一致性的独立维度——故事内部的因果逻辑：**

- [ ] **强制情节**：有没有"角色在该做某事时没做"的情况？
  - 例：主角知道有危险却不做准备、有重要信息却不告诉队友——除非人设本身就如此
- [ ] **角色行为合理性**：角色的每个重要选择是否有动机支撑？
  - 不能是"因为作者需要他这么做"
- [ ] **因果关系链**：大事件之间的因果关系是否成立？
  - A事件是否真的能导致B事件？中间的推理或逻辑链有没有跳跃？
- [ ] **信息流通**：角色获取关键信息的途径是否合理？
  - 不能"不知道怎么就知道了"

---

#### 审查域七：事件节奏与模式重复

> 本域检查跨大事件的节奏结构和情节模式，防止长篇连载中的结构性重复。

- [ ] **小高潮分布**：每个大事件内是否都有至少一个小高潮？是否存在某个大事件"全程铺垫没有爆发"的情况？
- [ ] **分卷大高潮完整性**：每一卷是否都有明确标注的 `⭐大高潮事件`？是否存在某卷"本卷大高潮"字段空白？是否存在一卷内标注了多个大高潮（应只有一个）？大高潮位置是否合理（非卷首、非全卷最后一章——大高潮后应有收尾空间）？
- [ ] **大事件节奏模式**：相邻大事件的节奏模式是否有变化？
  - 如果上一个事件是"日常→战斗→日常→小高潮"，下一个事件是否换了排列方式？
  - 如果上一个事件以战斗小高潮收尾，下一个事件是否以不同方式收尾？
- [ ] **情节模式重复**：不同大事件的核心冲突/转折方式/高潮类型是否有重复？
  - 例：是否每个大事件都以"主角突破→战胜强敌"收尾？
  - 例：是否每个大事件都以"收到求救信号"开始？
- [ ] **情绪曲线形态**：各卷的情绪曲线是否呈现差异化的形态（而非每卷都是"平→升→降"的相同波形）？
- [ ] **钩子类型分布**：回顾各事件结尾的钩子类型——是否存在某个钩子类型在短期内被反复使用？
- [ ] **小事件过渡模式**：跨大事件比较——不同大事件中的战斗事件过渡方式是否有全局性的重复？（如每次战斗事件都以"赶路遇敌"过渡）
- [ ] **重复性记录覆盖率**：`进度/重复性记录.md` 中记录的战斗策略/人物塑造事件/日常场景，是否呈现了跨大事件的重复趋势？（如果同一策略在记录中出现3次以上 → 系统性重复风险）

> 以上任一项发现重复模式 → 标注为"结构性重复风险"，向用户指出具体重复点，建议在后续大纲中调整。

---

### 第三步：综合评定

```
✅ 通过：所有审查域通过
⚠️ 警告：存在少量小问题，记录并在后续写作中注意
❌ 不通过：存在重大问题（设定全局矛盾/人物崩坏/伏笔大量遗漏/剧情逻辑断裂），必须处理
```

### 第四步：反馈与修复

1. 列出所有问题，按严重程度排序
2. 对每个问题提供修改建议或补充设定的建议
3. **用户修改后，重新审查受影响的部分**确认修复
4. 如果需要修改已写章节 → 修改后调用「**myworkflow:章节审查**」重新审查该章
5. 修复完成后更新 CLAUDE.md 的"当前创作状态"

## 后置更新步骤（本审查完成后必须执行）

1. **更新 CLAUDE.md**：
   - 更新"最近一次操作"为"全书一致性审查 → 日期"
   - 更新"待处理问题"（如有从审查中遗留的未修复问题）
   - 如果审查导致大纲/设定/人物有调整，同步更新相关字段
2. **更新审查记录**：在 `进度/` 下记录本次审查的日期、范围、结果（通过/警告/不通过）、遗留问题
3. **确认指南一致性**：确认审查过程中发现的指南偏离问题已全部记录或修复
4. **告知用户后续流程**：告知推荐的下一步操作（继续写作 / 先修复问题 / 调整大纲）

## 常见错误

| 错误 | 为什么错 | 正确做法 |
|------|---------|---------|
| 把"抽样检查"当成"跳过检查" | 旧章节不查=系统性矛盾可能潜伏 | 每5-10章抽1章检查关键设定一致性 |
| 审查域全部打勾但没读新章节 | 走形式不如不审——如果连章节都没读过就没法审 | 每个域至少读一遍近期章节的对应部分 |
| 发现问题不标注修改时间 | 问题记录后石沉大海，下一次审查还在原地 | 每个问题标注：发现日期、建议修改方案、优先级 |
| 只看设定不看剧情逻辑 | 设定一致但因果断裂——A事件能导致B事件不是因为设定对而是因为逻辑对 | 审查域六独立于设定检查，专门看因果 |
| 跨多章只审查最后一章 | 中间章节的伏笔、状态迁移被跳过 | 焦点"新增/修改的内容"，旧内容抽样 |

## 危险信号 — 停下先处理

- "感觉不太对但说不清" → 触发审查后每个域都打√ —— "说不清"的不对往往在审查域六（剧情逻辑），逐节排查因果链
- 审查结果全是✅但用户依然觉得不对劲 —— 可能是审查域没有覆盖的问题类型（如节奏/情绪），记录为已知并另行评估
- 伏笔记录中超过20%处于"待回收但已超计划回收章节" —— 伏笔债风险，优先处理最长期未回收的
- 力量体系出现"前期高手现在杂兵"且无世界观扩展解释 —— 通胀信号，要么加世界观扩展要么控制力量攀升

## 完成标志

- [ ] 设定在全书中保持一致（重点检查近期章节）
- [ ] 每个主要人物的弧光连贯合理
- [ ] 力量体系没有通胀或崩坏
- [ ] 所有伏笔均有记录且未遗漏回收
- [ ] 时间线没有矛盾
- [ ] 剧情逻辑自洽（强制情节/角色行为/因果关系/信息流通）
- [ ] 事件节奏与模式无结构性重复（小高潮分布/分卷大高潮完整性/大事件节奏/情节模式/情绪曲线/钩子类型/过渡模式）
- [ ] 检查结果已记录，问题已修复或标注为已知
