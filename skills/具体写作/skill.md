# Skill：具体写作 — 正文创作执行

> **⚡ 连续工作流**：此 skill 是「myworkflow:写前审查 → myworkflow:具体写作 → myworkflow:章节审查」自动链的第二环。由写前审查自动调用，完成后**必须立即调用「myworkflow:章节审查」，不得停下等待用户**。详见底部「连续工作流规则」。

## 触发场景
- 通过「myworkflow:写前审查」后，准备正式开始写一章正文
- 需要续写下一章

## 必需要素
- 已通过「myworkflow:写前审查」（所有检查项通过）
- 细纲已就绪
- **指南/风格定位.md**：本书专属风格和禁忌——写作全程的最高准则

## 推荐要素
- 上一章正文可参考（保持笔调一致）
- 设定/索引.md 和角色文件在侧可供随时核对

## 前置强制步骤

> **核心原则：指南文件是本书的"宪法"。** 写作过程中的每一个字都必须服从指南文件的风格定位和禁忌要求。

1. **读取本书指南文件**（写作全程保持在侧）：
   - `指南/风格定位.md` — 本书整体基调、风格要求 → **优先级最高**
   - `指南/核心卖点.md` — 本章是否体现差异化定位
   - `指南/书籍禁忌.md` — 绝不触犯任一条
   - `指南/AI记忆卡片.md` — 15 秒速读，确认不遗漏关键约束
   - `指南/特殊设定约束.md` — 本章涉及的设定是否有特殊行文约束
   → 写作中每写一段，潜意识中对照指南——节奏、用词、情绪基调是否符合？
   
2. **读取 CLAUDE.md**：确认当前写作位置、下一章内容、上一章审查状态

3. **读取已有细纲和角色文件**：读取 `大纲/细纲/{事件名}-细纲.md`（本章定位/类型/钩子）和本章涉及的角色文件（四维行为塑造/外貌与服饰/多标签融合），写作过程中保持在侧随时核对

4. **个性化调整写作**：
   - 如果指南要求"轻松幽默为主" → 叙述语调保持轻松，战斗场景也不宜过于血腥
   - 如果指南要求"短句为主" → 句子长度自觉控制
   - 如果指南有字数要求 → 严格遵循
   - 如果指南有禁止的描写类型 → 写作中完全避开

## 执行流程

### 第一步：准备工作

1. **打开进度文件**：确认当前写作位置
2. **打开当前细纲**：`大纲/细纲/{事件名}-细纲.md`，确认本章内容、看点、钩子
3. **打开写作参考**（写作全程保持在侧）：
   - `指南/风格定位.md` — 本书专属风格和禁忌（**优先级最高**）
   - `设定/索引.md` — 以便随时查阅专有名词、战力体系
4. **打开角色文件**：本章涉及的人物设定

---

### 第二步：写前自问（强制，对应通用手法各项）

动笔前，逐一确认以下问题。这是将通用写作手法转化为写作行动的关键步骤：

#### 一、本章定位

**步骤一：读取细纲的章节类型**

> 打开 `大纲/细纲/{事件名}-细纲.md`，读取以下细纲字段：
> - **章节类型**（必填）：战斗类 / 日常类 / 过渡类 / 组合（如"过渡+战斗"）
> - **本章剧情走向**（必填）：本章从哪开始、到哪结束，推动事件的关键一步是什么——确保写作不偏航
> - **必须提到的内容**（必填）：本章绝对不能遗漏的信息——关键人物出场/退场、重要设定揭示、伏笔埋设/回收
> - **结尾钩子**（必填）：细纲中预选的本章结尾钩子——写作时以此为基准，如果实际写出的钩子更好则写后同步回细纲
> - **所属小事件**（必填）：本章属于哪个小事件？在该小事件中的位置（过渡/核心/收尾）？
> - **小事件概览**表：了解当前小事件在整个大事件中的位置和与前后小事件的关系
> - **小事件构成**（头行 `# 小事件构成：战斗事件X个 + 日常事件X个 + 小高潮1个`）：确认当前大事件的整体节奏——是否已接近小高潮？前后还有多少事件？
>
> 同时打开 `大纲/{卷名}-完整大纲.md`，确认：
> - **大事件列表**：当前大事件是否被标注为 ⭐大高潮事件——如果是，本章写作强度应达到全卷最高水平，篇幅、情绪爆发、读者反应描写均需显著超过本卷内所有其他章节

根据细纲的章节类型，确定本章的写作指南。根据所属小事件的位置（过渡/核心/收尾），调整写作侧重——核心位置展开写足、过渡位置精简负载信息、收尾位置自然衔接下一小事件：

| 细纲章节类型 | 对应写作指南 | 篇幅范围 |
|------------|------------|---------|
| 战斗类 | 战斗章写作指南 | 小战斗半章~1章 / 常规1~3章 / 大高潮3~5章 |
| 日常类 | 日常章写作指南 | 半章~2章 |
| 过渡类 | 过渡章写作指南 | 半章~1章 |
| 组合（如"过渡+战斗"） | 按比例分别参考对应指南 | 各组成部分按各自篇幅范围 |

> AI 根据细纲的章节类型和细纲/写前审查上下文**自行判断**以下两项，无需提问用户：
> - 本章在情绪曲线上的位置（铺垫/发展/高潮/收尾）
> - 本章主导情绪（爽/紧张/感动/愤怒/期待/搞笑）——每章至少一种

**写作子类型**（在结构类型基础上的细化——帮助选择具体的写作技法）：
- 经营类内容 → 多出现在日常类章节中，侧重策略+成果感
- 探索类内容 → 多出现在过渡类或战斗类章节中，侧重未知感+信息增量
- 突破类内容 → 多出现在战斗类章节中，侧重压抑→释放+质变感
- 子类型不作为独立章节类型，而是提示该章侧重使用的写作技法

- [ ] **如果是新卷/新大事件的第一章**：开篇是否遵循了黄金三章逻辑（信息量适中、尽快抛出看点、拒绝过度铺垫）？

**步骤二：各类型写作指南**

根据第一步的结果，对照对应类型的写法建议：

**▎战斗章** — 核心：节奏 + 交互感 + 后果
（对应细纲类型：战斗类）

| 曲线位置 | 写作重点 | 推荐情绪目标 | 常见陷阱 |
|:---|:---|:---|:---|
| 铺垫 | 渲染敌人压迫感、埋战术伏笔、展示环境 | 紧张/期待 | 铺垫太长读者不耐烦 |
| 发展 | 交火拉锯、状态变化、地形利用 | 紧张/愤怒 | 回合制站桩、无交互感 |
| 高潮 | 决胜一击、信息差揭示、情绪爆发 | 爽/感动 | 秒杀过快、高潮被旁白稀释 |
| 收尾 | 战果展示、新威胁浮现、引出下章 | 期待 | 战斗后直接插入沉重剧情 |

**▎日常章** — 核心：人设展现 + 趣味互动 + 暗埋伏笔
（对应细纲类型：日常类）

| 曲线位置 | 写作重点 | 推荐情绪目标 | 常见陷阱 |
|:---|:---|:---|:---|
| 铺垫 | 日常琐事中植入细节，看似随意实则有用 | 搞笑/期待 | 纯流水账无信息增量 |
| 发展 | 角色互动加深关系，间接铺垫后续矛盾 | 搞笑/感动 | 水字数、对话无实质内容 |
| 高潮 | 搞笑名场面 / 温馨瞬间 / 关系转折 | 搞笑/感动 | 强行搞笑、情感过度用力 |
| 收尾 | 留下余韵，自然的悬念钩子 | 期待 | 收得太干净没有追读欲望 |

**▎过渡章** — 核心：信息负载 + 逻辑衔接 + 暗埋伏笔
（对应细纲类型：过渡类）

| 曲线位置 | 写作重点 | 推荐情绪目标 | 常见陷阱 |
|:---|:---|:---|:---|
| 铺垫 | 通过移动/等待/准备等自然场景负载信息——环境建立世界观、对话推进关系或埋伏笔 | 期待/好奇 | 纯粹时间流逝无信息增量（"在路上的第三天"） |
| 发展 | 信息逐步揭示——发现线索、拼凑情报、角色之间交换观点 | 好奇/紧张 | 信息一次性倾倒（说明书式交代） |
| 高潮 | 关键信息揭示或决定做出——"原来如此"或"就这么办" | 期待/紧张 | 揭示的信息不够"值钱"，读者觉得过渡在浪费篇幅 |
| 收尾 | 自然衔接到核心事件——过渡的终点就是战斗或日常事件的起点 | 期待 | 过渡收得太干净，与下一事件脱节 |

> **过渡章铁律**：过渡必须负载信息增量——环境描写建立世界观、角色对话推进关系或埋伏笔、发现线索指向后续剧情。纯粹的"在路上走了X天"不是过渡。

**▎写作子类型参考**（在以上结构类型基础上，按需查阅以下写作侧重）：

**经营类** — 核心：策略 + 成果感 + 成长可视化
（通常出现在日常类章节中）

| 曲线位置 | 写作重点 | 推荐情绪目标 | 常见陷阱 |
|:---|:---|:---|:---|
| 铺垫 | 展示现状问题/需求缺口，制造急迫感 | 紧张/期待 | 问题描述太冗长 |
| 发展 | 解决方案的实施过程，展示主角策略 | 爽/期待 | 过程太顺无波折 |
| 高潮 | 成果揭晓、危机化解、收益数据到账 | 爽/感动 | 成果抽象不具体（用数字说话） |
| 收尾 | 引出新问题/新需求，目标升级 | 期待 | 问题解决后无事可做 |

**探索类** — 核心：未知感 + 信息增量 + 世界拓展
（通常出现在过渡类或战斗类章节中）

| 曲线位置 | 写作重点 | 推荐情绪目标 | 常见陷阱 |
|:---|:---|:---|:---|
| 铺垫 | 进入新区域，渲染神秘和未知氛围 | 紧张/期待 | 环境描写过多无实质内容 |
| 发展 | 发现线索、逐一解读、逐步拼凑真相 | 期待/紧张 | 线索太直白无推理空间 |
| 高潮 | 重大发现 / 关键遭遇 / 隐藏解锁 | 爽/紧张 | 发现的秘密不够"值钱" |
| 收尾 | 暗示更深层的谜团，引出下章方向 | 期待 | 谜团全解完没有延续性 |

**突破类** — 核心：压抑 → 释放 + 质变感
（通常出现在战斗类章节中）

| 曲线位置 | 写作重点 | 推荐情绪目标 | 常见陷阱 |
|:---|:---|:---|:---|
| 铺垫 | 积蓄压力、展示瓶颈/困境、渲染不甘 | 紧张/愤怒 | 压抑过度读者先弃书了 |
| 发展 | 冲关过程、克服内心/外界障碍 | 紧张/感动 | 突破太容易缺乏含金量 |
| 高潮 | 突破瞬间、新力量/新境界的首秀 | 爽/感动 | 突破后立刻无敌破坏平衡 |
| 收尾 | 新能力的限制/代价，或适配新挑战 | 期待 | 突破完就没事干了 |

**通用法则**：
- 铺垫章占比不超过该类型章节总数的1/3 —— 读者耐心有限
- 连续2章铺垫后必须有一章小高潮或情绪波动
- 收尾时如果找不到钩子 → 说明本章可能不需要单独成章，考虑合并

#### 二、详略决策
对照以下清单，确认本章各部分的内容分配：

**本章需要一笔带过的内容**（≤200字）：
- 赶路、日常琐事、重复劳动——除非有剧情价值
- 简单战斗（一刀秒杀、碾压局）
- 连续的平淡日子过渡——绝不用"第X天做了……"的流水账结构

**本章需要给足篇幅的内容**（详写，不吝笔墨）：
- 核心冲突（对峙/谈判/争吵）——写透
- 主角做重大选择的心理斗争
- 新技能/新装备的首次使用——要有"首秀感"
- 情绪爆发点（喜怒哀乐的释放）
- 信息差时刻（揭露真相/发现秘密/识破阴谋）

> **判断标准**：写前对每个计划写到的场景自问——"删掉这一段，故事还能不能看懂？删掉后会不会'就这？'删掉后读者会不会'所以呢？'" 三个问题任一答"是"，压缩或删掉。

#### 三、本章结尾钩子预选

> **心法**：钩子的本质是在读者认知/情感中制造一个"缺口"。大脑有闭合需求，缺口越大追读欲望越强。但钩子应由情节自然生长出来——不要在动笔后才想钩子，而是在细纲阶段就预埋。

动笔前从以下工具库预选本章结尾的钩子（写到结尾时再验证）。

> AI 根据细纲中的本章看点、情绪曲线位置和情节发展，**自行从下方 13 式中选定**最适合的钩子类型。选定后告知用户选择理由，用户有异议时再调整。

**断章13式·招式菜单**

| 招式 | 核心操作 | 适合场景 |
|:---|:---|:---|
| 危险式 | 危险即将到来或刚发生时断章 | 战斗、探索、危机 |
| 谜团式 | 新谜团刚浮现就断章 | 悬疑、主线推进 |
| 决定式 | **主角做决定之前**断章 | 重大选择、转折点 |
| 冲突式 | 矛盾即将爆发时断章 | 对峙、谈判破裂 |
| 危机式 | 主角陷入绝境时断章 | 战斗、智斗 |
| 收获式 | 获得重要奖励但信息量极大时断章 | 升级、摸宝、任务完成 |
| 任务式 | 触发极具吸引力的新任务时断章 | 事件触发、卷末收尾 |
| 反转式 | 惊人真相被揭露时断章 | 卧底揭穿、隐藏身份 |
| 升级式 | 能力/境界即将突破时断章 | 修炼、突破 |
| 关系式 | 人物关系剧烈转折时断章 | 背叛、告白、决裂 |
| 信息差式 | 读者知道但角色不知道时断章 | 阴谋、埋伏、误解 |
| 情感式 | 情绪达到顶峰时断章 | 愤怒爆发、感动落泪 |
| 悬念式 | 长期悬念被正式回应时断章 | 身世揭秘、伏笔回收 |

> **技术铁律**：核心是"决定式"——永远断在主角**做决定之前**，不断在做决定之后。让读者问"然后呢？"，不让读者看到"然后他做了"。

**钩子自然的"因果律"**：
- ❌ 生硬：主角正庆祝，**突然**一个黑衣人闯入。→ "突然"用多了，读者觉得你在强行安排剧情
- ✅ 自然：庆祝时队友无意问"你这招谁教的？"，主角愣住了——他发现自己想不起来。钩子来源于情节发展的自然疑点，不是天降神兵

**找不到合适的钩子？** → 说明细纲的"本章看点"不够硬。回到大纲设计确认本章在情绪曲线上有明确作用，或考虑合并到上下章。

#### 四、关键情绪场景预判
本章如果有以下场景，提前确认处理方式：

- **愤怒/悲伤/紧张场景** → 用**展示**（动作、神态、环境），不要旁白告知"他很生气"
- **重大选择场景** → 写出**心理斗争**，给足篇幅
- **战斗场景** → 见下方「战斗场景写作锚点」
- **对话重场戏** → 见下方「对话写作锚点」

#### 五、语言表达铁律

动笔前确认以下语言层底线，写作中持续自查：

**脏话控制**：
- 不使用"你他妈""他妈"等脏话作为突出表达的手段，尤其在非愤怒场景
- 脏话只在角色极端情绪（暴怒、绝望）时作为人设一部分自然出现，不能成为作者"加强语气"的工具

**拒绝"不是…而是…"类转折句式**：
- **铁律：禁止使用"不是…而是…""不是…是…""不是…只是…""没有…而是…"等一切"否定A→肯定B"的转折句式**
- 这类句式的本质是作者跳出来替读者做判断——告诉读者"正确答案"是什么。用情节和动作让读者自己得出结论
- ❌ "他这么做不是因为恐惧，而是因为愤怒" → ✅ 写他攥紧的拳头、咬紧的牙关、一脚踹翻的椅子
- ❌ "她没有生气，只是失望" → ✅ 写她沉默了很久，起身收拾东西，没看他一眼就走了
- ❌ "这不是巧合，是必然" → 直接删掉——如果真是必然，前面情节应该已经让读者感受到了

**拒绝"和…一样…"类比较句式**：
- **铁律：禁止使用"和……一样……""跟……一样……""同……一样……""如同……一样……"等一切"A和B一样X"的比较句式**
- 这类句式的本质是偷懒——用B来"解释"A，本质上是作者没找到直接写A的方法，转而借助读者对B的认知来补位。这和"展示优先"原则完全对立
- ❌ "她的眼睛和星星一样明亮" → ✅ 写她转头看过来时，目光在昏暗的房间里格外显眼，或直接白描眼睛的具体特征
- ❌ "他和往常一样，推开门就走了进去" → 删掉"和往常一样"，直接写"他推开门走了进去"——如果"往常"的方式需要特别交代，用具体动作展示，而不是用比较句式一笔带过
- ❌ "那把刀和镜面一样反光" → ✅ "那把刀的刀面上能照出人影"
- 关键判断：这句话去掉"和……一样"之后，是否只剩下空洞的信息（如"她眼睛明亮"等于没说）？→ 是 → 说明原句也是空的，需要写出具体可见的特征，而不是换一种比较方式
- **频率硬上限："一样/不一样"及其近义词合计每章不超过3次**。以下词全部计入统计：一样、不一样、同样、相同、不同、类似、似的、近似、无异、没什么两样、没什么不同。此上限涵盖所有用法——包括已被禁止的"和……一样"比较句式（出现即违规）、对话中的合理口语使用、以及叙述中的所有近意表达。写作完成后逐章搜索以上各词统计总数，超量即改，无需额外批准——这些词的本质都是"用相对化表述替代直接描写"，3次已预留了充足空间

**拒绝对比/比较手法**：
- **铁律：尽量不要使用对比或比较的修辞手法来推进叙述——包括人物之间的横向对比、今昔对比、前后反差对比、环境氛围对比等**
- 对比/比较是作者强加在故事上的叙事框架——本质上是在"分析"而非"呈现"。读者不需要你告诉他"以前这里很热闹，现在很冷清"，他需要在冷清的描写中自己感受到"以前这里肯定很热闹"
- ❌ "与城东的繁华不同，城西一片破败" → ✅ 直接写城西的景象：倒塌的院墙、干涸的水井、空无一人的街道。读者自己会感知"破败"
- ❌ "上一次他来这里时，院子里挤满了弟子。现在只剩下满地落叶。" → ✅ "满地落叶铺得看不见地面。扫帚靠在门边，已经锈得推不动了。" 不需要告诉读者"以前有很多人"
- ❌ "别人渡劫时天雷滚滚，而他渡劫时万里无云" → ✅ 直接写他渡劫时的具体景象，不需要用"别人"做参照物
- 关键判断：文中出现"与……不同""和……不一样""相较于……""比起……""相比之下""而……却……"等对比标记时 → 删掉对比结构，直接写当前场景/人物的具体特征。如果直接写后信息量不够 → 说明需要更多具体细节，不是需要对比
- **例外**：人物对话中，角色自己说出对比/比较是合理的（作为该角色的心理活动或观点表达），但叙述性文字中不得出现

**比喻节制**：
- **铁律：除非绝对必要，不使用比喻——包括明喻（"像…""仿佛…""似乎…""…似的"）和暗喻（"A是B"）**
- 凡是能用直接白描替代的比喻，一律用白描
- 一节中出现1个比喻 → 审查是否必要；出现2个以上 → 必须至少删掉一个
- ❌ "他的怒火像火山一样爆发" → ✅ "他一拳砸在桌上"
- ❌ "她的笑容像春天的阳光" → ✅ 写她笑了之后周围人什么反应（侧面烘托），或直接写她笑时的具体特征
- 判断标准：删掉这个比喻，用白描写同一件事，效果是否更干净？→ 更干净 → 用白描；→ 画面客观受损（极少情况）→ 保留

**纯文本输出**：
- 正文内容为纯文本，**禁止在正文中使用任何 Markdown 格式标记**（包括粗体`**`、斜体`*`、分割线`---`、引用`>`、标题`##`、代码块等）
- 不依赖排版标记传达强调或情绪——语序、节奏、措辞本身即强调
- 章节文件首行可使用 `# 第XX章 标题` 作为结构标识，但正文内部不得出现任何标记

**破折号节制**：
- **铁律：正文中禁用破折号（——）。遇到破折号，一律用句号、逗号或动作描写替代**
- 破折号在网文写作中是语法拐杖——它的本质是在句子内部强行插入解释、转折或停顿，掩盖了句子结构本身的松散。去掉拐杖，句子才能真正站立
- 破折号的三大滥用场景及其替代方案：
  - **强行转折**：❌ "他推开门——房间里空无一人" → ✅ "他推开门。房间里空无一人。"
  - **插入解释性旁白**（作者跳出来补充说明）——这恰好是"展示>告知"的反面：❌ "他做了最坏的打算——对方不会放过他" → ✅ 写他检查了三遍门锁，把匕首压在枕头下。不需要告诉读者"他做了最坏的打算"
  - **制造虚假的戏剧停顿**：❌ "她终于明白了真相——这一切都是骗局" → ✅ "她终于明白了真相。这一切都是骗局。" 句号本身就是停顿，不需要破折号来"加戏"
- 判断标准：文中每出现一个破折号，删掉它，用句号或逗号替代。句子的节奏变好了还是变差了？→ 几乎总是变好。破折号拖慢阅读节奏，打断了情节的推进感
- **硬性上限：每章破折号最多出现1次**，且仅限对话中被外力打断的语流中断（"你难道就是——" 话还没说完，一剑已经刺来）。超出1次 → 必须先向用户说明理由并**获得明确批准**后方可使用。未被批准的超量破折号一律用句号/逗号/动作描写替代。但即便如此，优先考虑用省略号或直接写被打断的动作

**"是"字判断句节制**：
- **铁律：叙述性文字中"是"字判断句每章不超过2处**。以下句式全部计入统计：A是B / A就是B / 这正是… / 那便是… / A才是B / A不是B / A是不是B / A还是B——任何用"是"做谓语判断的句子
- "是"字判断句的本质是作者跳出来给读者下定义、贴标签、做总结——"这是什么""那是什么"——而不是通过情节和细节让读者自己认识。这与"展示优先"、"禁止直接性格描述"、"拒绝'不是…而是…'"是同一根源问题
- ❌ "他向来是个谨慎的人" → ✅ 写他每次推门前都先侧耳听三秒
- ❌ "这就是他一直等待的时刻" → ✅ "他等了很久。等到差点以为不会来了。现在它来了。"
- ❌ "愤怒是一种毒药" → 直接删掉——角色不需要替作者讲道理
- ❌ "她是个美人" → ✅ 写旁人看到她时下意识停住的动作，或直接白描一个具体的外貌特征
- **例外（不计入2次上限）**：
  - 人物对话中的"是"字句（作为角色口语自然使用）
  - 客观事实陈述：如"今天是三月十五""他是从东门进来的"（不涉及价值判断，只是交代信息）
  - 强调句"是…的"：如"他是昨天到的"（交代时间，非下定义）
- **判断标准**：删掉这个"是"字句，改成动作/白描/具体细节，效果是否更干净？→ 更干净 → 改写。如果真的是在交代一个非判断性的客观事实 → 不计入上限
- **硬性上限：每章叙述中的"是"字判断句（A是B / A就是B / 这便是… / 那正是… / 这才是… / A才是B等）合计 ≤2 处**。超出2处 → 必须先向用户说明每处保留的理由并**获得明确批准**。对话中的口语"是"、客观事实陈述、强调句"是…的"不计入上限

#### 六、人物塑造铁律

> **绝对禁止**直接描述人物性格（如"她是一个懒散的人""他是个果断的人""他向来谨慎"），必须通过动作、神态、语言、习惯细节来**呈现**。人物不是"说"出来的，是"活"出来的。

**每章底线**：每个主要人物在每章至少有一个展示性格的具体细节——一个独有动作、一句口头禅、一个习惯反应、一个微表情。

**人物的四维行为塑造（来自人物设计）**：写作前打开本章出场人物的角色文件，查看该人物在「阶段C+：行为塑造」中定义的四个维度——**动作特征、语言特征、神态特征、行为逻辑**。这四个维度是性格落地为文字的直接桥梁：

| 维度 | 写作时怎么用 |
|------|------------|
| **动作特征** | 该人物的习惯性动作是什么？本章在哪个场景自然嵌入这个动作？ |
| **语言特征** | 该人物的口头禅/惯用句式/语速节奏是什么？本章对话中如何体现？ |
| **神态特征** | 该人物的默认表情/情绪转换时的微表情/眼神特征是什么？本章在哪个情绪节点使用？ |
| **行为逻辑** | 该人物做决定的底层优先级是什么？遇到本章中的情境，他按什么逻辑做出反应？ |

> 四维不是每次出场全部使用——一章中分散嵌入几次动作、一次标志性神态、对话中体现语言特征、关键时刻展示行为逻辑。交替使用，角色自然活起来。

**人物的外貌与服饰（来自人物设计 阶段B+）**：写作前确认该人物的外貌与服饰设计——面部特征（脸型/眼型/特殊标记）、身体特征（体型/体态/身体标记）、服饰风格（身份层→性格层→处境层）。写作时：
- 外貌不在首次出场时一次性堆完——每次出场挑1-2个特征在动作中自然带出
- 服饰的"穿着方式"比"穿什么"更塑造人物——同一件制服，扣到最上面和敞开领口是两个性格

**多标签人物的行为融合（来自人物设计 阶段C+ ⑤）**：如果出场人物有多个性格标签：
- 确认主标签和副标签的优先级——日常场景以主标签为底色
- 确认副标签的激活条件——本章是否有触发副标签的情境？
- 副标签激活时，只在主标签底色上渗透纹理，不能完全切换人格——读者在任何场景都能认出"这还是同一个人"

**六项塑造技法（写前规划，写中执行）**：

**① 出场定型法** — 角色首次出场用2-3个具体细节锁定第一印象
- ❌ "走进来的是一个冷漠的男人" → ✅ "他推门进来，扫了一圈屋里的人，目光没在任何一个人身上停留超过一秒。拉开椅子坐下，掏出烟点上，整个过程没跟任何人打招呼。"
- 首次出场后读者应该能回答：这人什么性格？什么地位？什么情绪状态？

**② 习惯标记法** — 每个主要角色1-2个独有习惯，跨章节反复出现
- 动作习惯：紧张时转戒指、思考时敲桌面、不耐烦时舌尖顶腮
- 语言习惯：固定口头禅、标志性句式（短句/长句/反问/从不废话）
- 反应习惯：面对夸赞是谦虚还是得意、面对挑衅是冷静还是爆炸
- ⚠️ 不是每次出场都用——关键场景用一次，胜过每场都提

**③ 对比凸显法** — 同一事件，不同角色的反应对比
- 同一句话（"有敌情"）→ A立刻拔刀 / B皱眉先判断方向 / C下意识后退半步
- 对比一次 > 分别描述各十次

**④ 侧面烘托法** — 通过其他角色的反应间接塑造
- 某人一进屋全场安静了 → 此人有威慑力（不用旁白说"他是个有威严的人"）
- 小孩见到某人下意识躲到大人身后 → 此人可怕
- 队友分配任务时说"XX去不合适，让他去" → 侧面写出两个人各自的特点

**⑤ 成长可视化** — 性格渐变要有章节间的连续性
- 不要第一章懦弱、第二章突然勇敢 → 中间要有逐步积累的外界刺激和内心动摇
- 每章检查：本章的角色状态是上一章的自然延续还是断裂

**⑥ 外貌神态动作法** — 不是"描述"人物长什么样，而是在动作中"带出"外貌；微表情和小动作是性格的窗口
- ❌ 证件照式："她有一头长发，眼睛很大，身材高挑" → 读者跳过，什么都没记住
- ✅ 动作带出："她把长发往后一甩，低头时发梢扫过桌面" → 外貌有了，性格也有了
- 神态铁律：微表情 > 形容词——"嘴角抽了一下" > "他露出不屑的表情"；"耳根微微发红" > "她感到害羞"
- 动作铁律：小动作透露大性格——怎么走路（大步流星/蹑手蹑脚）、怎么坐下（大剌剌一坐/小心翼翼地只坐半边椅子）、怎么拿东西（一把抓过/双手接过）、怎么看人（直视/目光躲闪/扫一眼就移开）
- **身体在场**：角色不只在说话时存在——不说话的间隙，他在做什么？转笔、望窗外、反复摩挲茶杯沿——这些"无声细节"比对话更塑造人物
- 每章给每个主要角色至少一个"身体在场"的细节（他不是一个只会说话的声音）

**写前自查**：
- [ ] 本章出场主要人物的角色文件是否已打开？其**四维行为塑造**（动作/语言/神态/行为逻辑）是否已确认——本章至少从四个维度中各取一个特征落地？
- [ ] 出场人物的**外貌与服饰风格**是否已确认？本章挑哪1-2个外貌/服饰特征在动作中带出？
- [ ] 如有**多标签人物**：主/副标签优先级是否已确认？本章是否触发副标签激活情境？激活后副标签只在主标签底色上渗透纹理（而非完全切换人格）？
- [ ] 细纲/构思中是否出现了"她是X的人" / "他性格X" / "他向来X"等直接性格描述？→ 出现即删，转为动作呈现
- [ ] 本章每个主要角色是否规划了至少一个"这个角色独有的"行为细节？→ 没有 → 现在补充
- [ ] 两个角色互换台词/动作后是否还能分辨？→ 能 → 人设区分度不够，需要强化
- [ ] 本章角色的反应模式是否与之前章节一致（除非有成长弧线推动）？
- [ ] 本章是否有角色首次出场？→ 是 → 是否规划了2-3个出场定型细节（含外貌与服饰特征）？

> 以上六项技法的**写中执行清单**见第四步「锚点E：人物塑造场景」——写前规划好后，写作时对照锚点E逐幕执行。

#### 七、标点符号规范

动笔前确认以下标点底线，写作中持续自查。所有正式中文内容必须遵循 GB/T 15834—2011 标准。**严禁中文段落中出现英文半角点号替代中文全角标点。**

**句末点号**：
- 陈述句用"。"，疑问句用"？"，感叹句用"！"
- 禁止使用英文句点`.`、问号`?`、叹号`!`作为中文句末点号

**句内点号**：
- 分隔句子成分用全角逗号"，"
- 并列词语用顿号"、"
- 并列分句且分句内有逗号时用分号"；"
- 提示语、引出列表用全角冒号"："

**标点层级铁律（顿号/逗号/句号）**：

> ⚠️ **这是本章最重要的标点规则——AI 默认行为是用句号结束每一句话，这在中文网文中是致命的。你必须主动对抗这个倾向。**

**核心原则：逗号连接，句号收束。一段之内，句号是例外，逗号是常态。**

- **铁律：一段之内能用逗号的地方，一律不用句号。** 网文阅读追求"一口气读完"的流畅感。句号 = 文气断裂 = 阅读节奏破碎。一段之内，句号仅用于：①段落最后一句话（收束全段）；②前后两个句子各自完全独立且断开后阅读节奏明显优于逗号连接（这种情况应很少）
- **逗号:句号比例**：全章逗号与句号之比应 ≥ 3:1。低于 2:1 → 文气严重断裂，必须重写。写完一章后自查：如果逗号数和句号数差不多，说明你几乎每句话都用句号结尾——这是 AI 的默认坏习惯，必须逐段修改
- **句子内部用"，"分隔**：复句中的分句之间、较长的句子成分之间用逗号分割——逗号承担句子内部的结构切分
- **顿号"、"仅用于极小并列分割，尽量少用**：两个或几个词/短语的并列列举（如"刀、剑、枪"），用顿号。但顿号不应越界替代逗号——动作之间用逗号不用顿号（❌"他推门、走进来、坐下"→ ✅"他推门，走进来，坐下"）

**❌ 句号过多（AI 默认坏习惯）vs ✅ 逗号流畅（正确网文节奏）对比**：

```
❌ 他推开门。房间里空无一人。桌上放着一封信。他走过去拆开来看。
   → 4 个短句全部用句号断开。读者读起来像在蹦跳，无法沉浸。这就是 AI 默认写出来的东西。

✅ 他推开门，房间里空无一人，桌上放着一封信，他走过去拆开来看。
   → 逗号连接，一气呵成。读者一口气读完一整段，节奏流畅不被打断。

❌ 剑光闪过。对方后退了三步。他的手腕在发麻。这一剑比想象中更沉。
   → 战斗场景用句号断开，节奏全毁。战斗应该让读者喘不过气。

✅ 剑光闪过，对方连退三步，他的手腕一阵发麻——这一剑比想象中更沉。
   → 逗号让动作连续发生，读者感受到的是连续的压迫感而非碎片。
```

**判断标准**：写完一段后，逐个检查句号——尝试替换为逗号。替换后读起来更顺畅 → 改逗号。替换后语义严重混乱 → 保留句号（这种情况应很少）。如果一段之内句号超过 3 个 → 几乎肯定有问题，逐句检查是否可以合并。

**引号**：
- 一律使用全角双引号"“”"与单引号'‘’'，嵌套时外层双引号，内层单引号
- 禁止使用英文直双引号 `" "` 或单引号 `' '`
- 判断标准：中文段落中引号必须是全角弯引号，不能用直引号

**括号**：
- 中文段落使用全角圆括号（）
- 禁止使用英文半角括号 `( )`

**书名号**：
- 使用双书名号《》，内部嵌套用单书名号〈〉
- 非书籍、作品名不得滥用书名号

**破折号与省略号**：
- 破折号规则见「语言表达铁律 → 破折号节制」（每章≤1处且仅限对话被打断）。如经批准使用，必须用"——"（两个 em dash，二字宽），禁止用`--`或`—`代替
- 省略号用"……"（六个点，二字宽），禁止用`...`或`。。。`
- 破折号（——）和省略号（……）均占两字宽，整体不可断裂——遇到行尾要么全放上一行，要么全移下一行

**连接号与间隔号**：
- 数值范围使用浪纹"～"（如"10～20 kg"），地点起止使用一字线"—"（如"北京—上海"）
- 英文、数字中的连接使用半角短横`-`
- 间隔号用全角点"·"（如"约翰·史密斯"）

**中英文、数字混排**：
- 中文与西文之间加一个半角空格（例：使用 Python 进行数据分析，获得 15% 的提升）
- 中文与数字之间加一个半角空格（例：共 20 个项目。但"20世纪""第1章"等序号/年份不加空格）
- 小数点用半角`.`，千分位分隔用半角`,`——禁止出现全角数字、全角字母
- 英文句内标点保留原样：他提到了"Hello, world!"这个程序
- 货币、单位符号前不强制加空格，如 ¥128 万、20℃，需结合语境统一

**排版禁则（强制执行）**：
- **行首禁则**：行首不能出现 ， 。 、 ； ： ！ ？ … 》 ） " ' 】 ——换行时应将禁止字符挤回上一行或调整字距
- **行末禁则**：行末不能出现 " ' 《 （ ［ 【 ——这些前一半符号不能孤立在行尾
- **破折号/省略号不可断裂**：占两字宽，整体不可拆分
- 在纯文本写作中，通过手动断行回避禁则——写完一章后从头扫一遍行首行末

**写前自查**：
- [ ] 是否已区分全角中文标点与英文半角标点？中文段落确认使用全角标点？
- [ ] 中英文混排处是否记得加半角空格？
- [ ] 省略号是否准备用"……"而非`...`或`。。。`？
- [ ] 引号是否为全角弯引号"“”"而非英文直引号`"`？

### 第四步：关键场景写作锚点

写作过程中，当遇到以下场景时，对照对应的技法清单。这是将通用手法嵌入写作过程的直接方式。

#### 锚点A：战斗场景

先确认本章战斗的类型，再按对应指南写。

**速战型（碾压/秒杀）** — 突出"落差感"
- 预热：先渲染对手的强大/嚣张，让读者期待
- 破防：主角一招破掉对手的自信，落差即爽点
- 收尾：围观者的震惊反应比战斗过程本身更值钱
- 篇幅控制：渲染对手占70%，战斗过程占30%

**拉锯型（势均力敌）** — 突出"交互感"
- 有来有回：A攻→B防/闪/反击→A应对（拒绝回合制站桩）
- 有后果：每下攻击都有真实后果——伤口影响动作、地形破坏限制走位
- 节奏三段式：试探（快）→ 周旋（慢，穿插心理战）→ 绝杀（快）
- 穿插状态变化：体力消耗、技能CD、地形被利用

**智斗型（以弱胜强）** — 突出"信息差"
- 埋设：战前铺垫主角的布置或伏笔
- 揭示：战斗中揭示"原来刚才那步是这个用意"
- 反转：利用对手思维盲区完成反杀
- 篇幅控制：战斗前准备占40%，战斗过程占60%

**通用检查清单**（无论哪种类型）：
- [ ] **动作具体化**：不要写"他使出一记猛击"——写拳头怎么挥出的、打到哪、对方什么反应。拒绝喊技能名的呆板对轰
- [ ] **有交互感**：不是A打一套→B打一套的回合制站桩。A攻击→B格挡/闪避/反击→A应对
- [ ] **穿插情绪**：心理活动、面部神态、简短怒骂。几句话即可，不要变嘴炮
- [ ] **短段短句**：节奏快的地方段落短、句子短
- [ ] **战力检查**：主角表现是否在设定等级之内？有无越级碾压或机械降神？
- [ ] **团队配合**（如涉及多人）：靠配合取胜，不是小角色突然爆发

**负向案例**：
- ❌ "他使出一记破天拳，对方被击飞。他又使出一记裂地掌，对方吐了口血。" → 回合制站桩，无交互感无后果
- ❌ 主角突然爆发秒杀全场，前文无任何铺垫 → 机械降神，读者觉得你在耍赖
- ❌ 满级号在低等级区横着走，毫无悬念地秒杀一切 → 无冲突无张力，读者不会觉得爽只会觉得无聊

#### 锚点B：对话重场戏

先确认对话类型，再按对应指南写。

**冲突型对话（争吵/对峙/谈判）** — 突出"火药味"
- 短促：句子短、节奏快，不给对方喘息
- 打断：互相截话，不留空隙
- 动作穿插：拍桌、冷笑、转身、逼近——用动作替代语气词
- 沉默也是武器：一方突然沉默比继续争吵更有压迫感

**情报型对话（信息交换/解谜/计划）** — 突出"效率"
- 拒绝说明书：角色不会说出对方已知的信息（"你知道的，我们从小一起长大……"→ 删掉）
- 信息分层：核心信息放在对话高潮亮出，次要信息一笔带过
- 问答要有障碍：A问→B不一定答——B可能隐瞒、误解、岔开话题

**情感型对话（告白/和解/决裂）** — 突出"潜台词"
- 言外之意比说出口的重要：主角说"没事"——读者知道有事
- 停顿和省略号比长篇大论有力
- 配合小动作：绞手指、不敢对视、下意识靠近或后退

**通用检查清单**（无论哪种类型）：
- [ ] **人设入声**：粗人说话直接，文人说话委婉，上位者说话留三分。不要把所有角色写成一种口吻
- [ ] **用对话展现关系**：称呼（"你"/"您"）、语气（恭敬/随意/命令）、是否打断对方——这些比直接说"他们关系很好"有效十倍
- [ ] **节奏匹配场景**：紧张时对话短促（一两个字），轻松时对话可以更长。生死关头不应该有长段独白
- [ ] **避免刻板古风腔**：不发"哈哈""呵呵""罢了罢了"等刻意古风/翻译腔，除非是特定角色人设
- [ ] **吐槽控制**：每章1-2次双关吐槽为上限，不要密集轰炸

#### 锚点C：情绪高潮场景

写到情感爆发点（爽点/感动/愤怒释放）时：

**展示优先——常见情绪的转化清单**：
- ❌ "他无比愤怒" → ✅ "他攥紧了拳头，指节发白，声音从牙缝里挤出来"
- ❌ "她非常感动" → ✅ "她张了张嘴，什么都没说出来，眼眶先红了"
- ❌ "全场震惊" → ✅ 写出具体谁是什么反应：XXX的杯子掉在地上，XXX张大了嘴，XXX下意识站起来
- ❌ "气氛很紧张" → ✅ 没有人说话，只听见钟在走。额头的汗顺着脸颊滑下来滴在桌上
- ❌ "他很紧张" → ✅ 他把手心在裤子上擦了又擦，每次呼吸都数着拍子

**外貌神态——拒绝"形容词标签"，用可见细节**：
- ❌ "她很漂亮" → ✅ "她走进来时，门口那桌两个男人同时停下了筷子"
- ❌ "他看起来很疲惫" → ✅ "他眼眶下面泛着青，下巴上冒出一层胡茬，坐下来的时候肩膀塌着，整个人往下坠"
- ❌ "他长相普通" → ✅ 写一个具体特征：左眉尾有一道旧疤、笑的时候右边的酒窝先出来、说话时习惯歪着头
- ❌ "她露出不屑的表情" → ✅ "她嘴角抽了一下，目光从他脸上移开，多看一眼都不愿意"
- ❌ "他强忍着泪水" → ✅ "他盯着天花板看了很久，喉结上下滚了滚，再低头时眼睛已经红了，但声音跟平时一样稳"

**篇幅法则**：
- 情绪高潮是读者最期待的部分，**不要为了赶进度草草带过**
- 高潮后的反应描写（围观者震惊、对手不甘、队友落泪）比高潮本身更值得给篇幅——这是读者的情绪共鸣出口
- 如果读者期待的中心场景你用了不到200字就写完 → 严重预警，回到大纲检查情绪曲线

**情绪转换禁忌**：
- ✅ 热血 → 温暖 → 振奋（自然过渡）
- ❌ 热血战斗后突然插入沉重哀悼 → 情绪断崖，读者会出戏
- ❌ 轻松日常中突然插入残酷身世揭露 → 除非有过渡铺垫

**战斗后情绪处理建议**：
- 战斗后用温暖治愈的方式处理悲伤（酿酒纪念而非葬礼仪式）
- 胜利后不要立刻进入下一个战斗——给读者情绪回落的空间

**负向案例**：
- ❌ "主角很生气，他决定要让对方付出代价。" → 这是告知，读者感受不到愤怒的重量
- ❌ 期待已久的场景用了100字打发 → 读者失望感堪比被欺骗
- ❌ 情绪在两种极端之间反复横跳（狂喜→暴怒→狂喜）→ 读者情感麻木，再无感染力

#### 锚点D：本章结尾

> **连载铁律：每一章都不是完整的故事。** 结尾的唯一作用是制造"然后呢？"——"开启"下一章，而非"关闭"本章。任何让读者觉得"这章讲完了，可以放下"的结尾都是失败的结尾。

写到结尾时，重新审视之前预选的钩子：

**第一步：排查禁止结尾（出现任一项 → 删掉那段，用钩子替代）**

- [ ] 总结式："这一天的经历让他明白……" / "回顾这次……" — 连载不需要帮读者总结本章
- [ ] 收束式："夜色渐深，一切归于平静" / 环境描写收束 — 这是"关灯睡觉"的信号
- [ ] 展望式："明天的路还很长……" / "未来充满了无限可能" — 这是"作者觉得该收尾了"
- [ ] 感悟式："他陷入沉思……" / "或许这才是真正的……" — 角色替读者总结，剥夺阅读体验
- [ ] 口号式："他一定会变得更强！" / 决心宣言 — 喊得越响，读者关得越快
- [ ] 闭环式：本章开头的问题在结尾彻底解决 — 这一章不是完整故事，闭环 = 没有追读理由
- [ ] 安静收尾：角色独自安静地坐着/躺着 / "他一个人站在窗前" — 安静 = 能量归零
- [ ] 拖沓式：钩子抛出后又加了2-3行解说/抒情/环境描写 — "作者不信任读者能看懂"，钩子即终点
- [ ] 补充式：钩子句后再追加"但他知道/他意识到/这意味着/或许……" — 写完钩子立刻断章，不追加任何文字

> 以上9类禁止结尾，触犯任一项 → **必须修改**。不是"可以优化"——是必须改。

> **钩子铁律**：钩子句 = 本章最后一句。写完钩子立刻断章，不追加任何解说、抒情、感悟、环境描写。读者只需要"然后呢？"，不需要你解释"这意味着什么"。

**第二步：验证钩子的自然度与有效性**
- 这个钩子是情节自然发展的结果（✅），还是为了悬念硬塞的（❌）？
- 删掉结尾最后一段，能直接衔接下一章吗？→ 能，说明钩子有效
- 读者读完会问"然后呢？"（✅）还是"嗯，讲完了"（❌）？

**第三步：血泪教训·钩子三大陷阱**
- ⚠️ **天降神钩**：全章99%平淡种田，章末突然有人叛变。→ 钩子与主线毫无因果，读者觉得被侮辱智商
- ⚠️ **悬而不决**：第一章结尾收到恐吓信，接下来30章都在写日常再不提及。→ 消耗读者信任，最终弃文
- ⚠️ **机械重复**：每章结尾都是"突然一把飞刀袭来"。连续5章，读者全骂。→ 钩子疲劳，再好的钩子也失灵

> **技术铁律**：结尾是"开启"不是"关闭"。读者读完本章应该想"然后呢？"

#### 锚点E：人物塑造场景

> 本节是第二步·六「人物塑造铁律」六项技法的**写中执行清单**——动笔前在第二步完成人物规划，写作时对照此处逐幕执行。

**写前必查**：打开本章出场主要人物的角色文件，确认：
- **四维行为塑造**（动作/语言/神态/行为逻辑）——本章至少从四个维度中各取一个特征落地
- **外貌与服饰风格**——本章挑1-2个外貌/服饰特征在动作中自然带出（不堆在首次出场）
- **多标签融合**（如有）——确认主/副标签优先级，本章是否触发副标签激活情境

写到涉及人物展示的关键段落时，对照以下执行清单：

**人物登场/首次出场**：
- [ ] 用2-3个具体动作/细节锁定第一印象（拒绝"他是X的人"）
- [ ] 出场方式符合人设：急性子直接推门，谨慎者先观察，嚣张者不等通报
- [ ] 其他角色的反应是否烘托了此人的定位？

**人物对话时**：
- [ ] 每句话是否符合人设语音（粗人/文人/上位者/卑下者）？
- [ ] 称呼和语气是否体现了与对方的关系（"你"/"您"、恭敬/随意/命令）？
- [ ] 对话中是否穿插习惯动作/微表情（不只是"他说""她道"）？
- [ ] 角色不说话时在做什么？旁听者的身体语言是否体现了态度（抱臂/走神/点头/看别处）？

**人物外貌与神态（写作时逐幕检查）**：
- [ ] 外貌特征是否来自人物设计的「阶段B+：外貌与服饰风格」设计？（脸型/眼型/特殊标记/体态——只写已设计的特征，不临时编造）
- [ ] 外貌是否在动作/情节中自然带出，而非"证件照式"罗列？（每角色每次出场只挑1-2个最具辨识度的外貌特征写，不要每次都全脸描写）
- [ ] 服饰的"穿着方式"是否体现了性格？（同一件制服的不同穿法本身就是人设展示）
- [ ] 是否至少有一个微表情细节（嘴角/眉头/眼神/耳根/手指/喉结）替代了形容词标签？
- [ ] 神态变化是否可见、可感知？（"脸沉了下来" > "他变得不高兴了"；"眼底的光暗了一下" > "他失望了"）
- [ ] 不同角色的神态反应方式是否不同？（同一件事：A冷笑/B皱眉/C移开目光）

**人物动作与身体语言（写作时逐幕检查）**：
- [ ] 角色是否有标志性身体语言？（走路姿势、坐姿、手势、看人的方式）
- [ ] 关键动作是否具体可见？（"他抄起杯子砸在墙上，碎片溅了一地" > "他愤怒地发泄"）
- [ ] 角色在不同场景下的身体状态是否一致？（紧张时的习惯小动作、放松时的姿态）
- [ ] 非说话时角色是否仍然"身体在场"？（站着怎么待着、手里在做什么、目光在看哪里）

**人物做决定时**：
- [ ] 决定方式是否体现性格？果断者不犹豫，谨慎者权衡再三，莽撞者不思考后果
- [ ] 有没有通过"他怎么做的决定"让读者看到性格，而不只是"他做了什么决定"？
- [ ] 决定的"过程"是否可见？写出他收集了什么信息、问了谁、忽略了什么、内心哪两个念头在打架——但只写到"纠结中"，不断在"他最终选了哪个"上（配合钩子：答案留给下一章）
- [ ] 不同角色对同一困境做出的判断是否不同？（同一局面：A判断"打"、B判断"撤"、C判断"先试探"——每个判断都是人设的延伸）

**人物处事方式（性格即选择）**：
- [ ] 遇到阻碍时的第一反应是否体现人设？（暴躁者直接撞上去/圆滑者绕路/算计者等别人先上）
- [ ] 与人合作时的姿态？（独狼自己闷头干/领导者先分配任务/新手先观察学习）
- [ ] 面对弱者/强者时的态度差异？（对下属和对上司是否两副面孔——如果有，写出这种切换）
- [ ] 解决问题的思路是否因人而异？（同一个问题：A用武力/B用关系/C用信息/D用钱——让解决方案本身成为人设标签）

**人物面对压力时（最佳人设展示窗口）**：
- [ ] 极端情况下反应是否符合基础人设？冷静者可能慌但不会崩溃，暴躁者可能怒但不会冷静分析
- [ ] 压力下的"第一反应"最暴露真实性格——不要浪费这个窗口
- [ ] 压力下的微表情和身体反应？（僵住了/手在发抖但脸在笑/喉结上下滚了一下但声音稳住）

**配角是否存在**：
- [ ] 本章配角是否沦为"推动剧情的道具"而无任何个性细节？→ 哪怕一句话、一个动作，让配角也有血肉
- [ ] 本章是否出现两个角色"说话方式一样"？→ 遮住名字读对话，还能分辨出谁是谁？

**执行自查**：
- [ ] 是否有角色做出了"不符合人设"的事？→ 如果是成长弧线推动 → 需前文铺垫；如果不是 → 删改
- [ ] 本章是否有人物"被剧情推着走"而非"性格驱动选择"？→ 检查关键决定：换一个人做同样决定是否合理？

### 第五步：写作过程中的即时管理

**边写边查**：
- 涉及已有设定/人物时，核对设定文件，不凭记忆
- 通过 `设定/索引.md` 快速定位

**新创内容即时记录**（两种方式）：
- **方式A（推荐）**：正文中先写，写完本章后统一补充到对应文件
- **方式B**：写作中暂停，立即补充——适合新概念较多的情况

**控制篇幅**：每章≥2500字，不灌水

**如果写卡住了**：
1. 重读上一章结尾 + 当前细纲 → 确认本章要达成的目标
2. 仍然卡 → 尝试先写本章最容易写的一个场景（不一定要从开头写起）
3. 持续卡 → 检查细纲是否合理，回到「myworkflow:大纲设计」调整细纲

**情绪张力维护**：
- 写作中如果感觉某个段落"平淡"，对照详略决策——如果是该压缩的内容，一句话带过；如果是该展开的内容，检查是否用了"告知"而非"展示"
- **连续2章平淡铺垫** → 本章需用强钩子制造期待，或在章中安排一个小爽点/情绪波动
- **连续高强度情绪** → 给一章过渡让读者喘口气（但结尾仍需钩子维持期待）
- **写着写着觉得"这段好无聊"** → 读者也会觉得无聊。果断压缩或换个写法，不要硬写
- **卡在段落衔接处** → 用"因果链"检查：上一段到下一段有逻辑因果还是"然后……然后……"的流水账？
- **感觉人物"不鲜活"** → 检查是否全在"告知性格"而非"展示性格"；给这个角色一个独有动作或一句只有他才会说的话；检查是否缺少外貌神态动作细节——读者"看不见"这个人物
- **写到配角时"不知道他该干什么"** → 配角不是主角的附庸——即使在一旁站着，他也有自己的态度（不耐烦/好奇/冷漠），写出这个态度
- **连续几段对话只有"他说""她说"** → 人物只剩声音没有身体——补充微表情、手势、身体姿态、视线方向
- **写着写着发现偏离了细纲的章节类型** → 如果偏离后更好，同步更新细纲的类型标注；如果只是写偏了，回到正轨
- **过渡段/章感觉"空洞"** → 检查是否在纯时间流逝——过渡必须负载信息增量（环境描写/角色对话/线索发现）

## 通用写作雷区速查

以下问题在写作中最容易被忽视，完成一章后快速扫一眼：

| 雷区 | 表现 | 后果 |
|:---|:---|:---|
| 告知替代展示 | "他很生气"而非通过行动表现 | 读者代入感归零 |
| 回合制战斗 | A打完B打，无交互无后果 | 战斗在念说明书 |
| 说明书对话 | 角色说出对方已知的信息 | 读者出戏 |
| 禁止结尾 | 触犯总结/收束/展望/感悟/口号/闭环/安静/拖沓/补充任一类 | 追读欲望归零——连载每章都不是完整故事 |
| 脏话强调 | "你他妈""他妈"作为语气加强 | 脏话变廉价，读者对真正愤怒场景脱敏 |
| "不是…而是…"类转折句式 | "不是…而是/是/只是…""没有…而是…"等否定A肯定B | 作者替读者判断，剥夺阅读体验 |
| "和…一样…"类比较句式 | "和/跟/同/如同……一样……"等借助B解释A | 偷懒写法——用比较替代直接描写，和展示优先对立 |
| "一样/不一样"及近义词泛滥 | 全章"一样/不一样/同样/相同/不同/类似/似的/近似/无异/没什么两样/没什么不同"等合计超过3次 | 相对化表述替代直接描写——每次"一样"都是一次"没直接写"的信号 |
| 对比/比较手法 | "与……不同""相比之下""而……却……"等横向/今昔对比 | 作者强加的分析框架——读者不需要"分析"，需要"呈现" |
| 不必要比喻 | 明喻"像…/仿佛…"或暗喻"A是B" | 文字臃肿——白描比比喻更干净有力 |
| 直接性格描述 | "他是X的人""她向来X" | 人物扁平化，读者记不住 |
| 人物同质化 | 所有角色说话方式一样、反应模式一样 | 读者分不清谁是谁 |
| 配角道具化 | 配角只为主角服务，无个性细节 | 世界像舞台布景，失真 |
| 证件照式外貌 | "她有一头长发，眼睛很大"罗列五官 | 读者跳过，人物无辨识度 |
| 神态标签化 | "露出不屑的表情""显得很生气" | 读者看到的是形容词，不是人物 |
| 动作概括化 | "他愤怒地发泄""她紧张地等待" | 没有画面，读者感受不到 |
| Markdown 标记 | 正文内使用 `**粗体**` `*斜体*` `---` 等 | 破坏纯文本阅读体验，排版标记是写作的拐杖 |
| 破折号依赖 | 正文中使用——做转折/解释/停顿 | 语法拐杖——拖慢节奏。硬性上限：每章≤1处且仅限对话被打断，超量必须先获批 |
| 性格驱动断裂 | 角色决定与性格无关，换谁做都一样 | 人物沦为剧情提线木偶 |
| 钩子后追加文字 | 钩子句后又加解说/抒情/感悟 | 钩子失效——读者已得到"解答"不需要追读 |
| 天降神钩 | 钩子与主线毫无因果 | 读者觉得被愚弄 |
| 持续平淡 | 连续多章无情绪波动 | 读者弃书走人 |
| 过渡空洞 | 过渡章/段只有"赶路/移动/等待"无信息增量 | 读者跳过不读——过渡沦为填充物 |
| 类型偏离 | 细纲标注"战斗类"但正文写成日常 | 读者期待的战斗没发生——或更新细纲类型标注 |
| 英文标点侵入 | 中文段落中使用英文半角 `,` `.` `?` `!` `:` `;` `"` `'` `()` 等 | 排版混乱，读者感知到文本不专业——破坏沉浸感 |
| 省略号错误 | 使用 `...` 或 `。。。` 替代 "……" | 视觉不统一，中文阅读习惯中 `...` 是英文省略 |
| 中英文无空格 | "使用Python进行数据分析"——中文与英文/数字之间无半角空格 | 挤在一起影响可读性，违反中文排版惯例 |
| 引号错误 | 使用英文直引号 `"..."` 或 `'...'` 替代全角弯引号 "…" | 中英文引号混淆，视觉不协调 |
| 排版禁则违规 | 行首出现逗号/句号/顿号等禁则字符，或破折号/省略号断裂 | 排版不专业，严重违反中文排版规范 |
| 句号过多 | 一段之内用句号频繁断开，把本该一气呵成的动作流/情绪流切成碎片 | 阅读节奏破碎，读者无法沉浸——网文追求"一口气读完"，能用逗号连接就不要用句号断开 |
| "是"字判断句泛滥 | 叙述中"他是X的人""这就是Y""愤怒是Z"等每章超过2处 | 作者替读者下定义——与展示优先、禁止直接性格描述同一根源问题 |

## 常见错误

| 错误 | 为什么错 | 正确做法 |
|------|---------|---------|
| 跳过写前自问直接写 | 没确认本章定位就动笔——写完发现偏离了细纲或情绪曲线不对 | 自问虽小但防止方向跑偏 |
| 写卡住硬写也不查细纲 | 卡住往往是细纲不够具体或方向偏了，硬写产出大概率废弃 | 重读上一章结尾+当前细纲，确认本章目标 |
| 写完一章不更新进度/时间线/伏笔 | 不更新的后果=下一章写前不知道写到哪里了 | 第七步必须执行：写作进度+时间线+伏笔+CLAUDE.md |
| 直接触发章节审查但忘记更新文件 | 章节审查需要时间线和细纲做对照，但它们是旧的 | 先更新文件，再触发章节审查 |
| 战斗写完跳过结尾钩子 | 打完架直接"夜色降临"收束——读者看完了，关掉了 | 战斗后设置下一步的钩子（胜利的连锁反应或新威胁浮现） |
| 钩子后追加解说/抒情 | 写完钩子觉得"读者可能没看懂"，又解释了两句——钩子失效 | 钩子句即最后一句，写完立刻断章，信任读者的理解力 |
| 用"她是X的人"介绍角色 | 偷懒式人物塑造——读者什么都记不住 | 用动作、习惯、口头禅、微表情让读者自己"认识"这个角色 |
| 多标签人物写成"切换人格" | 平时慵懒，触发腹黑后从动作到语言完全变成另一个人——读者觉得角色"崩了" | 副标签只在主标签底色上渗透纹理——读者在任何场景都能认出"这还是同一个人" |
| 配角写成"工具人" | 配角出场只为主角服务（送道具、传话、当靶子），无个性细节 | 哪怕只有一句对话一个动作，让配角有自己的"人味" |
| 人物决定与性格脱节 | 谨慎者不权衡就莽、莽撞者突然深思熟虑——读者觉得角色"崩了" | 每个关键决定反向检查：这个决定是否符合该角色一贯的行为模式？ |
| 外貌"证件照" | 新角色出场罗列五官清单（"一双X眼，高鼻梁，薄嘴唇"） | 读者跳过——改为在动作中带出1-2个最具辨识度的特征 |
| 情绪用形容词标签 | "不屑地说""愤怒地吼""紧张地答" | 读者看到的是词，不是人——全部替换为微表情和身体动作 |
| 正文中使用破折号 | 用——做转折/解释/停顿 | 破折号是语法拐杖——删掉破折号，用句号断开或用动作描写代替。硬性上限每章≤1处，超量必须先获批 |
| 用"和……一样"偷懒 | 用比较句式间接解释，而非直接描写 | 删掉比较结构，写出具体可见的特征——读者需要"看到"而非"被比较" |
| "一样/不一样"及近义词超量 | 全章"一样/不一样/同样/相同/不同/类似/似的/近似/无异/没什么两样/没什么不同"等合计超过3次 | 搜索以上各词统计，超量即改。每次出现都是一次"没直接写"的信号 |
| 用对比/比较推进叙述 | 用横向对比或今昔对比来交代变化或差异 | 直接写当下的具体景象——让读者从细节中自己感受对比，不需要作者"分析" |
| 不查看细纲的章节类型直接写 | 细纲标注"过渡类"但按日常章写法写——写出来与细纲规划脱节 | 写前必读细纲的章节类型字段，对照对应写作指南 |
| 组合类型章写偏比例 | 细纲标注"过渡+战斗"但过渡写了80%、战斗只有20% | 按细纲规划的比例分配篇幅，过渡部分精简、核心部分展开 |
| 中文段落用英文标点 | 中文叙述中使用英文 `,` `.` `?` `!` `:` `;` 等半角点号 | 全部替换为对应的中文全角标点——中文段落中英文标点是排版事故 |
| 中英文混排无空格 | "使用Python进行数据分析获得15%的提升" | 中文与西文/数字之间加半角空格："使用 Python 进行数据分析，获得 15% 的提升" |
| 省略号写成"..."或"。。。" | 用三个英文句点或三个中文句号替代省略号 | 省略号统一用"……"（六个点，二字宽），出现即改 |
| 引号用英文直引号 | 对话/引用使用 `"..."` 或 `'...'` 替代全角弯引号 | 一律替换为全角弯引号"“”"（外层双引号，内层单引号） |
| 句号过多断节奏 | 一段之内频繁用句号断开，把本该一气呵成的段落切成碎片 | 逐句检查：每个句号处尝试替换为逗号，替换后读起来更顺畅 → 改逗号。仅段落末尾和强语义转折处保留句号 |
| 顿号乱用替代逗号 | 动作序列用顿号连接（"他推门、走进来、坐下"）而不是逗号 | 顿号仅用于极小的并列分割（词/短语列举），动作承接用逗号 |
| 叙述中"是"字判断句超量 | 每章"他是X""这就是Y""那是Z"等判断句超过2处 | 删改至 ≤2 处（对话口语/客观事实不计），超出必须先获批——"是"=作者替读者下定义 |

## 危险信号 — 停下重新检查

- 本章写到一半还没明确结尾用什么钩子 —— 说明本章在情绪曲线上缺乏明确目的，回到细纲确认
- 连续三章使用同一种钩子类型 —— 读者产生钩子疲劳，必须换招式
- 某章内容与细纲严重偏离但用户说"没关系" —— 需要确认：是真的比细纲更好，还是写着写着跑偏了？
- 写后自检全部打勾但只花了30秒 —— 自检不是走形式，每个检查项至少给10秒
- **未运行自动化检测脚本就标记完成** → 脚本是强制步骤，不是可选项。未运行 `python "$HOME/.claude/plugins/webnovel-studio/tools/chapter_check.py"` 并确认硬性规则项全部 `passed=true` 之前，本章不算完成
- 自动化脚本返回 `failed` 但手动改勾为通过 → 脚本检测到的硬性规则违规（字数/禁止句式/标点）必须修改正文后重新运行脚本确认，不得手动覆盖
- 写到结尾时发现"不知道该用什么钩子" → 不是钩子库不够用，是本章在情绪曲线上缺乏明确目的——回到细纲确认本章的剧情定位
- 初稿字数不足2000字但觉得"该写的都写了" → 不是写不长，是该展开的场景用了"告知"一笔带过——检查是否有核心冲突/情绪场景被压缩
- 结尾用了"夜色渐深""他陷入沉思""明天会更好"等收束语 → 这不是"文笔好"，这是连载自杀——立即替换为钩子
- 钩子写完后忍不住又加了几句"解释"或"抒情" → 拖沓式/补充式禁止结尾——删掉钩子后的所有文字
- 文中出现了"她是一个X的人""他向来X" → 人物塑造铁律违规——立即改写为动作/神态/语言呈现
- 写作时没有打开角色文件确认四维行为塑造 → 人物容易写得"知道性格但不知道怎么写"——写作前必须确认出场人物的动作特征/语言特征/神态特征/行为逻辑
- 写作时没有查看人物的外貌与服饰设计（阶段B+），临时编造外貌特征 → 外貌前后不一致，读者无法建立稳定的视觉印象
- 外貌描写是"五官清单"（"他有一双X的眼睛，X的鼻梁，X的嘴唇"）→ 证件照式外貌，读者只看不记——改为动作带出
- 多标签人物在副标签激活后完全变了一个人（动作/语言/神态全部切换）→ 读者觉得角色人格分裂——副标签只在主标签底色上渗透纹理
- 情绪只用形容词标签（"不屑地""愤怒地""紧张地"）→ 读者看到的是词不是画面——全部替换为微表情和身体动作
- 角色不说话时在场景中"消失"了（只有轮到台词才被提到）→ 人物沦为说话工具——补充身体在场的细节
- 回头读本章对话，遮住名字分不清哪句话是谁说的 → 人设语音区分度严重不足，重写对话
- 本章配角全部"为剧情服务"而没有任何独立于剧情的个性细节 → 世界失真，给配角加血肉
- 正文写完了但标题还是动笔前那个泛泛的暂定名 → 正文写完后回头看，往往有更精准的概括。标题是读者对本章的第一印象，别让它停留在"预生产状态"
- 出现"像""仿佛""似乎""似的""如同"等比喻标记 → 逐个审查是否可以用白描替代；一节超过1个比喻 → 必须删减
- 正文中出现了 `**粗体**` `*斜体*` `> 引用` `---` 等 Markdown 标记 → 纯文本铁律违规——全部移除
- 文中出现了破折号（——）→ 逐个审查。硬性上限：每章≤1处且仅限对话被外力打断。出现第2个破折号必须向用户说明理由并获批
- 文中出现了"和……一样""跟……一样""同……一样"等比较句式 → 铁律违规——删除比较结构，用直接白描写出A的具体特征
- 搜索全章"一样/不一样/同样/相同/不同/类似/似的/近似/无异/没什么两样/没什么不同"等近义词，合计>3次 → 超量违规——逐一审查每次出现是否必要，压缩到≤3次
- 叙述中出现"与……不同""相比之下""而……却……""曾经……现在……"等对比标记 → 铁律违规——删除对比框架，直接写当前场景的具体细节，让读者自己感受
- 写着写着发现本章内容类型与细纲标注的章节类型严重偏离 → 停下来确认：是写偏了（回到正轨），还是实际内容确实更好（同步更新细纲类型标注）
- 过渡章写完后自己读一遍发现没有任何信息增量 → 过渡章违规——补充环境/对话/线索中的至少一种信息负载
- 中文叙述中出现了英文半角标点（`,` `.` `?` `!` `:` `;` `"` `'` `()` 等）→ 标点规范违规——全部替换为对应中文全角标点
- 省略号用了 `...` 或 `。。。` → 标点规范违规——替换为"……"
- 中文与西文/数字之间缺少半角空格（如"使用Python"）→ 排版规范违规——加上空格
- 行首/行末扫查发现禁则违规（行首出现逗号/句号等，行末出现左引号/左书名号等）→ 排版禁则违规——通过手动断行回避
- 破折号或省略号在行尾被截断 → 排版禁则违规——整体移至下一行
- 一段之内句号超过 3 个 → 几乎肯定文气断裂——逐个句号尝试替换为逗号，合并碎片化的短句为逗号连接的长句流。如果逗号总数和句号总数差不多 → AI 又犯了"每句都用句号结尾"的默认坏习惯，必须逐段修改
- 动作序列用了顿号（"他推门、走进来、坐下"）→ 顿号越界替代逗号——改为逗号
- 搜索全章叙述中的"是"字判断句，"A是B / A就是B / 这便是… / 那正是… / 这才是…"等合计 >2 处 → 超量违规——保留最重要的2处，其余改写为动作/白描/具体细节，或逐处向用户申请批准
