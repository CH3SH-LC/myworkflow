# Skill：人物设计 — 三层人物体系构建

## 触发场景
- 项目启动时需要系统设计主要人物、临时人物
- 写作过程中需要添加新角色（新反派、新队友、本章出场的龙套）
- 发现现有人物行为与设定不一致，需要修正或补充人物设定
- 新增人物关系或调整人际关系网

## 必需要素
- 无硬性前置——即使设定和大纲尚未完成，也可以先设计人物草稿
- 但最终定稿前必须与设定和大纲对齐（见下方关联Skill）
- **指南/风格定位.md**：文风定位决定人物的整体风格——必须在设计前读取，设计全程遵守

## 推荐要素
- **设定/战力体系.md**：战力体系约束人物的能力上限和成长路径
- **大纲/粗纲.md**：剧情走向影响人物的弧光设计和出场时机

## 前置强制步骤

> **核心原则：指南文件是本书的"宪法"。** 人物风格必须服从指南文件中的风格定位——轻松文风不宜设计过于沉重的角色，严肃文风不宜设计过于儿戏的角色。

1. **读取本书指南文件**：读取 `指南/` 文件夹下所有文件，特别关注：
   - `指南/风格定位.md` — 本书整体基调 → 决定人物风格（幽默型 vs 严肃型 vs 混合型）
   - `指南/书籍禁忌.md` — 人物设定不能违反（如"禁止出现XX类型角色"）
   - `指南/特殊设定约束.md` — 是否有约束人物设计的特殊设定
   → 如果 `指南/` 文件夹为空或仅有基本骨架 → 提示用户先调用「myworkflow:本书个性化设计」完成指南文件的深度定制
   
2. **读取 CLAUDE.md**：了解当前创作状态、已有角色列表、当前写作位置（确认需要哪些人物）

3. **读取已有角色**：检查 `角色/` 文件夹下是否已有角色文件，避免重复创建

4. **个性化调整**：
   - 如果指南要求"主角必须讨喜" → 阶段F情感锚点侧重"共鸣感"和"崇拜感"
   - 如果指南要求"反派要有魅力" → 阶段I加强"可以理解但不可原谅"的设计
   - 如果指南有禁止的人物类型 → 跳过对应设计
   - 如果指南有文风偏好 → 阶段B属性速写和阶段C反差设计应符合文风

## 目标
帮助用户设计三种层次的人物：主要人物（完整弧光）、临时人物（鲜明但精炼）、龙套（有名字、极少剧情参与、非纯粹路人），确保每个人物在故事中发挥适当的角色。

## 使用方式

### 批量模式（项目启动时）
按流程依次设计所有需要的人物，从主要人物到龙套，建立完整的人物库。

### 独立模式（写作中加人）
写作过程中需要添加新人物时，直接跳到对应类型设计：
1. 确定类型（主要/临时/龙套）
2. 执行对应类型的提问和输出
3. 存入 `角色/` 文件夹
4. 如果是写作中途添加，在正文中标记出场章节

## 执行流程

### 第一步：读取现有内容

**批量模式（项目启动时）** —— 全面读取：
- `角色/` 文件夹下已有的人物设定
- `指南/风格定位.md` —— 确认本书文风（影响角色风格）
- `设定/战力体系.md` —— 确认战力边界（影响角色战力设计）
- `大纲/粗纲.md` —— 确认剧情走向（影响角色弧光与出场时机）
- 当前写作章节范围（影响需要补充哪些人物）

**独立模式（写作中途加人）** —— 按需读取：
- 检查 `角色/` 下是否已有此角色的文件（避免重复创建）
- 如果是**龙套**：只需确认当前事件的细纲（出场章、剧情功能），以及 `设定/` 中相关设定（确保出场合理性）
- 如果是**临时人物**：读取当前事件的细纲 + 相关设定文件
- 如果是**主要人物**：按批量模式处理——需要读取粗纲、战力体系、风格定位以设计完整弧光

## 类型一：主要人物

**适用范围**：主角、重要配角、长期反派。参与大段剧情，有完整的人物弧光。

### 阶段A：基础信息

- "姓名是什么？有没有外号/别名？"
- "年龄、性别、外貌特征（有识别度的即可，不需要从头到脚）"
- "身份地位：出身背景、当前职业/位置"
- **关联检查**：出身背景是否符合世界观设定？

---

### 阶段B：属性速写 — 快速成像

在深入性格之前，先用"标签组合"快速搭建角色的视觉和气质印象。这是角色能否被一眼记住的基础。

从以下类别中各选1-2项，组合成角色的初始画像：

| 类别 | 可选标签（举例） |
|------|----------------|
| **性格底** | 傲娇、无口、天然呆、元气、中二、腹黑、毒舌、沉稳、慵懒、偏执 |
| **体型** | 高挑、娇小、匀称、魁梧、纤细 |
| **发型** | 双马尾、黑长直、短发、卷发、单马尾、乱发 |
| **发色** | 黑、白、金、红、蓝、银、灰 |
| **瞳孔** | 异色瞳、赤瞳、蓝瞳、金瞳、无高光眼 |
| **衣着** | 制服、西装、和服、铠甲、斗篷、紧身战斗服、随意便装 |
| **标志物** | 眼罩、绷带、眼鏡、发带、面具、项圈、蝴蝶结、泪痣、呆毛、疤痕 |
| **身份标签** | 勇者、魔王、穿越者、转学生、杀手、侦探、社畜、流浪者 |

> **原则**：属性之间要有化学反应。比如"傲娇"+"呆毛"+"异色瞳"是一个完整的视觉单元，"无口"+"疤痕"+"斗篷"是另一个。不要堆砌——3-5个高辨识度标签胜过十个散乱标签。

**自问**：剥离掉所有剧情，仅靠这几个属性标签，这个角色能不能在读者脑海中留下一个轮廓？

---

### 阶段B+：外貌与服饰风格 — 让视觉标签落地为可见形象

阶段B的属性速写用标签快速搭建了角色的视觉轮廓（"黑长直 + 赤瞳 + 制服"），但写作时需要知道这个角色**具体长什么样、穿什么、怎么穿**——以及外貌和服饰如何反映性格与出身。

#### ① 外貌设计 — 有辨识度的面孔

外貌设计的目标不是"画一张漂亮的脸"，而是让读者能**记住并辨认**这个角色。

**面部特征**（选取2-3个最具辨识度的点——不是五官清单）：

| 类别 | 可选方向 | 气质暗示 |
|------|---------|---------|
| **脸型** | 瓜子脸、圆脸、鹅蛋脸、方脸、长脸 | 脸型本身无优劣——瓜子脸偏精致、圆脸偏亲和、方脸偏坚毅 |
| **眼型** | 杏眼（圆而明亮）、丹凤眼（细长上挑）、桃花眼（眼尾微弯）、下垂眼（眼尾向下） | 眼睛是神态的载体——眼型决定了"默认表情"的基调 |
| **眉型** | 剑眉（英气）、柳叶眉（柔和）、粗眉（憨直）、断眉（有故事）、挑眉（不屑/傲气） | 眉型影响整个面部的情绪倾向 |
| **特殊标记** | 泪痣、疤痕、雀斑、酒窝、虎牙、伤耳、断眉 | **一个标记胜过千言万语**——它既是辨识度，也是过往经历的线索 |

> **辨识度 > 美观度**：读者记不住"五官精致的标准美人"，但记得住"左眉尾有道旧疤、笑的时候右边酒窝先出来的那个人"。

**身体特征**（与出身和经历一致）：
- **体型与肌肉分布**：常年战斗的人身体线条紧实，书斋学者清瘦，劳动者粗壮——身体是职业和生活方式的外显
- **体态**：站姿、走路姿态——挺直（军人/贵族）、驼背（长期伏案/自卑）、松弛（慵懒/随性）、戒备（永远侧身站、下意识观察出口）
- **身体标记**：旧伤、纹身、胎记、老茧的位置——每个标记暗示一段经历
- **关联检查**：身体特征是否符合出身背景？贵族小姐的手不应有干粗活的茧（除非有意设计反差）

#### ② 服饰风格 — 衣服是性格的外延

服饰不是"给角色穿件好看的衣服"，而是**角色性格、身份、处境的视觉表达**。

**服饰设计的三个层次**：

| 层次 | 解决的问题 | 示例 |
|------|-----------|------|
| **身份层** | 穿什么符合他的身份/职业？ | 军人穿军装、学生穿校服、流浪者穿破旧但实用的大衣 |
| **性格层** | 在身份约束内，如何通过穿着表达个性？ | 同样穿校服——规矩者扣到最上面一颗，随性者敞开领口袖子卷到手肘 |
| **处境层** | 当前处境如何影响穿着？ | 逃亡中——衣服有破损但关键部位保护完好；刚获地位——穿得好但略显刻意 |

**服饰风格方向**（在阶段B衣着标签基础上细化）：

| 风格方向 | 具体表现 | 暗示的性格/身份 |
|---------|---------|---------------|
| **实用主义** | 方便活动优先、口袋多、耐磨面料、无装饰 | 务实、战斗者、底层出身 |
| **精致考究** | 面料上乘、剪裁合身、配饰齐全、颜色协调 | 贵族/精英、在意他人目光 |
| **随意不羁** | 衬衫不扎、纽扣错位、搭配不在意规则 | 自由散漫、不拘小节、或故意反叛 |
| **标识鲜明** | 统一制服、家族纹章、势力徽记、固定配色 | 归属感强、身份认同、或被迫从属 |
| **隐藏性穿着** | 斗篷/兜帽/高领遮面、掩盖身材的宽松衣物 | 有秘密、在逃、或回避关注 |

> **核心原则**：衣服的"穿着方式"比"衣服本身"更塑造人物。两件同样的制服——一个熨得笔挺、袖口扣紧，一个皱巴巴、袖子卷到手肘——读者一眼就能看出这两个人的性格差异。

**配饰与标志物**（呼应阶段B的标志物标签，但赋予来历）：
- 每个配饰应该有来历或功能：戒指是母亲遗物、眼镜是亡友的、匕首是第一次任务的奖励
- ❌ "她戴了一条好看的项链" → ✅ "她脖子上挂着一条褪色的银链，坠子藏在衣领里，从不让别人碰"
- 配饰也是伏笔工具——看似装饰品的物件，可能在后续剧情中揭示功能或意义

#### ③ 外貌与性格的关联原则

| 原则 | 说明 |
|------|------|
| **外貌暗示性格，不宣告性格** | "嘴角天生向下，看起来总像在生气" → 读者感知到"不好接近"，不是旁白告知 |
| **服饰反映价值观** | 一个把所有钱花在武器保养上但穿补丁衣服的人——价值观不言自明 |
| **外貌的"矛盾"即故事** | 贵族小姐的手上有干粗活的茧 → 她有一段没说的过去 |
| **不同场景换装 = 人设展示窗口** | 战斗时穿什么、日常穿什么、正式场合穿什么——每次换装都是展示性格侧面的机会 |

#### 外貌与服饰速查示例

以"慵懒的流浪剑客"为例，展示外貌和服饰如何与性格标签统一：

| 维度 | 具体设计 | 反映什么 |
|------|---------|---------|
| **面部** | 总是半睁的丹凤眼、右颊一道浅疤从颧骨划到耳根、笑的时候右边酒窝先出来 | 慵懒+有过去+偶尔的笑有感染力 |
| **身体** | 瘦但肩膀宽、站姿松垮——站着时重心总在一条腿上、手指指节有老茧 | 有实力但不紧绷、常年握剑 |
| **服饰** | 深灰色旧斗篷（边缘已磨毛）、内穿褪色的藏蓝布衣、腰带上的剑鞘比衣服新得多 | 不在乎外表、所有资源投入武器——价值观一目了然 |
| **细节** | 斗篷胸口内侧缝了一个小小的褪色徽记——属于一个已被灭门的流派 | 过去、动机、待揭示的伏笔 |

> **写作提示**：外貌和服饰不在角色首次出场时一次性堆完——每次出场挑1-2个特征在动作中自然带出。具体方法见「myworkflow:具体写作」skill 的锚点E：人物塑造场景。

### 阶段C：性格核心 — 一句话定义 + 反差设计

#### 一句话概括
- **"用一句话概括这个人是谁。"**
  - "一个表面懒散但关键时刻永远靠得住的退役老兵"
  - "一个聪明到能看透一切但善良到愿意装傻的公主"

#### 性格关键词（3-5个）
- 关键词之间要有张力，"谨慎"和"冲动"共存才能产生内部冲突
- 性格的成因是什么？过去有什么经历塑造了现在的他？

#### 反差设计（核心技法）

**反差是角色魅力的源泉。** 在性格关键词和属性标签之间寻找矛盾，制造化学反应。从以下五个维度寻找至少一个反差：

**① 外表 vs 能力**（最直观的反差）
- "林黛玉倒拔垂杨柳"型：外表娇小柔弱，战力却极为强悍（反之亦然）
- 例：穿着JK制服拿魔杖的魔法少女，却用魔杖进行物理打击

**② 外表 vs 真实自我**（表里不一）
- 看似邪恶的反派，内心极度善良；看似温柔的好人，骨子里冷酷算计
- 例：外表冷漠的杀手，私下是重度猫奴

**③ 身份 vs 性格**（宏观错配）
- 身份是统治世界的魔王，性格却让他在日常中手忙脚乱
- 例：贵为公主，性格却是市井泼皮——在朝堂上装优雅，回宫立刻脱鞋抠脚

**④ 能力/性能的错配**（武器/技能层面）
- 设计了某个强大能力，但有一个让人发笑的副作用或使用限制
- 例：拥有最强火焰魔法，但每次使用后会发烧一整天

**⑤ 概念的错配**（文化/视觉符号的融合）
- 将毫不相干的视觉或文化符号融合
- 例：科幻机甲 + 道法符箓、西洋骑士 + 江湖侠客

> **临时人物也可用反差**：临时人物在有限篇幅内，一个精心设计的反差往往就是读者记住他的唯一理由。在后面的临时人物部分会详述。

### 阶段C+：行为塑造 — 让性格落地为可见的行为

性格核心定义了"这个人物是谁"，但写作时你需要知道"这个人物怎么做、怎么说、怎么反应"。**行为塑造**就是将抽象的性格标签翻译为读者可见的动作、语言、神态和决策模式——让性格在纸面上活起来。

这不是指特殊癖好或怪癖，而是**符合人物标签的自然行为方式**——是性格在具体情境中的必然外显。一个慵懒的大姐姐不是因为有"爱打哈欠"的怪癖才慵懒，而是慵懒的性格自然表现为打哈欠、慢悠悠的动作、嘴上嫌麻烦但手上不停。

为每个主要人物，从以下四个维度定义其行为塑造方式。四个维度必须指向同一个性格核心，互相配合而非各自为政。

---

#### ① 动作特征 — 身体如何表达性格

人物的性格会在日常动作中自然流露——不是刻意表演，而是性格驱动身体的惯性。

自问：
- "这个性格的人，独处时和在人前分别会有什么习惯性动作？"
- "遇到压力/惊喜/尴尬时，他的身体第一反应是什么？"
- "他的动作幅度是大是小？节奏是快是慢？"

| 性格标签 | 动作特征示例 |
|---------|------------|
| 慵懒型 | 经常打哈欠、伸懒腰、走路慢悠悠、喜欢靠着/趴着说话、拿东西只伸一只手去够、起身时先叹气 |
| 急性子 | 说话时手指敲桌面、走路带风、坐下后抖腿、等人时反复看时间/来回踱步、吃东西快 |
| 沉稳型 | 动作幅度小但精准、坐下前先整理衣摆、说话时手掌向下压表示克制、从不慌忙翻东西 |
| 傲娇型 | 被说中时猛转头、递东西时别过脸、嘴上拒绝时手上动作反而更温柔、心虚时摸后颈 |

> **关键**：读者看到这个动作能感受到性格，但不会觉得"这个人在演"。动作是性格的泄露，不是性格的广告牌。

#### ② 语言特征 — 说话方式即性格签名

同样一个意思，不同性格的人说出来完全不同。定义人物的语言特征，让读者"听声音就能认出是谁在说话"。

自问：
- "他的口头禅或惯用句式是什么？（不是刻意设计的标语，而是性格驱动的说话习惯）"
- "他的语速、节奏、句子长短有什么特点？"
- "面对不同对象时（朋友/敌人/陌生人/上位者），语言风格会如何变化？"

| 性格标签 | 语言特征示例 |
|---------|------------|
| 慵懒型 | 口头禅"太麻烦了""真不想动"，**但说这话的同时已经在动手解决问题**；语速偏慢，爱用省略号；认真起来语言反而变得简洁有力——反差揭示本质 |
| 毒舌型 | 陈述句带刺但不带脏字；夸人的话必须包一层讽刺的外壳；真正感动时反而说不出话；关心的表达是"你死了我会很麻烦" |
| 热血型 | 句子短、感叹号多；先说再做（甚至不做就说）；喜欢用"绝对""一定""最"等绝对化词汇；被打脸时会说"那是因为我还不够强" |
| 腹黑型 | 话只说七分，留三分让人猜；表面关心实则试探；用提问代替陈述；关键时刻的沉默比平时的话更有分量 |

> **关键**：语言特征和动作特征互相配合才能产生化学反应。慵懒型角色一边说"太麻烦了"一边已经把问题解决了——语言和行动的反差本身就是性格在纸面上的立体呈现。

#### ③ 神态特征 — 面部与微表情的默认设置

神态是连接内心与外表的最短路径。在对话和场景描写中，神态特征的复用会让角色的"面孔"在读者心中越来越清晰。

自问：
- "没有特殊事件时，这个人脸上通常是什么表情？（默认表情）"
- "情绪转换时有什么标志性的神态变化？（开心/愤怒/悲伤/惊讶时的微表情）"
- "眼神有什么特征？——眼神是神态的核心"

| 性格标签 | 神态特征示例 |
|---------|------------|
| 慵懒型 | 半睁眼、眼神涣散但偶尔聚焦时很锐利；遇事时先叹气再微笑；笑起来眼睛弯成一条线、笑容有感染力 |
| 冷酷型 | 面瘫为主，但眉头微动暴露真实情绪；嘴角的微小变化是情绪的唯一线索；真正愤怒时反而表情完全消失 |
| 天然呆 | 歪头表示困惑、反应慢半拍的表情延迟、被夸奖时先愣住再脸红、认真思考时皱眉但看起来很可爱 |
| 腹黑型 | 微笑是默认表情，但笑容幅度随危险性增加而增加；眯眼时最危险；被戳穿时笑容不变但眼神瞬间变冷 |

> **关键**：神态不能孤立使用——同一个微笑配上放松的肢体和配上握紧的拳头，传达的是完全相反的信息。神态必须与当下的动作、语言形成统一的情绪信号。

#### ④ 行为逻辑 — 性格驱动的决策引擎

以上三者（动作、语言、神态）是外在表现，行为逻辑是驱动它们的**内在规则**。它决定了角色面对选择时的底层优先级——让角色的每个选择都有"他确实会这么做"的说服力。

自问：
- "遇到问题时，他的第一反应模式是什么？（逃避/直面/先观察/先求助/先自己扛）"
- "他做决定时，最优先考虑的是什么？（安全/效率/人际关系/原则/利益/面子）"
- "什么情况下他会做出违背自己表面性格的行为？"——这个边界定义了性格的弹性范围，也是角色的高光时刻来源

| 性格标签 | 行为逻辑示例 |
|---------|------------|
| 慵懒型 | 口头嫌麻烦但从不真正拒绝求助——内心信条是"能帮就帮"；选择最简单直接的方式解决问题，不是因为懒，而是因为务实；真正的底线被触碰时会比任何人更认真更拼命 |
| 偏执型 | 任何选择都会先过滤"这能让我接近目标吗"；善意来时先怀疑动机；但一旦信任某人，会不计代价守护——因为"我信的人就是我的世界" |
| 热血型 | 做决定时直觉先于理性、情感先于利害；被质疑时不是反思而是加码证明；但面对真正的无力感时（救不了想救的人），热血会冷却为更深沉、更坚定的东西 |
| 算计型 | 所有选择都做成本收益分析，包括人际关系；对"欠人情"极度敏感——必须尽快还清以恢复平衡；唯一的例外是"这个人在我的计算之外" |

> **四维一致性原则**：动作、语言、神态、行为逻辑必须指向同一个性格核心。如果行为逻辑是"务实高效"，但动作特征写成"拖泥带水"，读者会感到割裂——除非这种矛盾本身就是设计好的反差（此时需要在反差设计中明确标注，让读者能识别这是有意的张力而非写作失误）。

#### ⑤ 多标签人物的行为融合

真实的人物往往不止一个性格标签。一个角色可能同时"慵懒"又"腹黑"，在特定情境下还展现出"护短"的一面。单标签只能塑造扁平角色，多标签的叠加和融合才是立体人物的来源。

##### 步骤一：为每个标签拆解四维特征

人物有几个性格标签，就为**每个标签**分别写出其动作、语言、神态、行为逻辑。参考上方四个维度的标签对照表，逐一提取——每个标签都会在四维上留下独特的印记。

##### 步骤二：排优先级 — 主标签与副标签

| 层级 | 作用 | 出场占比 |
|------|------|---------|
| **主标签**（1个） | 人物的默认状态——日常场景中稳定表现的性格底色 | ~80% 出场时间 |
| **副标签**（1-2个） | 特定情境下激活——为人物增加层次和意外感 | ~20% 出场时间 |

> 主标签决定"读者最常看到的这个人是什么样的"，副标签决定"这个人在什么情况下会让读者感到意外"。

##### 步骤三：定义切换触发 — 什么情境激活副标签

每个副标签必须有**明确的激活条件**。不是"有时候腹黑有时候不腹黑"——而是"什么情境下腹黑面会露出来"：

- 例：主标签"慵懒"，副标签"腹黑" → 平时懒洋洋，但在**涉及自身核心利益的关键谈判中**腹黑面激活——语言变得话中有话、神态从半睁眼变成眯眼微笑
- 例：主标签"热血"，副标签"沉稳" → 平时冲动热血，但在**队友受伤、他必须独自扛起责任时**沉稳面激活——动作从张扬变克制、语言从句句感叹变完整句

> **切换触发必须是具体的情境类型**，不能是"有时候A有时候B"的模糊描述。

##### 步骤四：写出融合后的综合表现 — 四维融合表

不要写成"这个场景用标签A，那个场景用标签B"的机械切人格。好的融合是：**主标签的底色上，渗透着副标签的纹理**。

以下以"慵懒（主）+ 腹黑（副）"为例，展示每个维度的融合方式：

| 维度 | 主标签（慵懒）打底 | 副标签（腹黑）渗透 | 融合后的综合表现 |
|------|-----------------|-----------------|---------------|
| **动作** | 打哈欠、慢悠悠、喜欢靠着 | 关键对话时手指无意识地轻敲桌面、观察时动作短暂停顿 | 平时瘫在椅子里像没骨头，涉及利益时——姿势不变，手指开始有节奏地敲扶手 |
| **语言** | "太麻烦了"、语速慢 | 话只说七分、用提问代替陈述 | "太麻烦了不想管"——说这话的同时，已经用三个问题把对方的底牌套干净了 |
| **神态** | 半睁眼、叹气再微笑 | 眯眼时最危险、笑容幅度随危险性增加 | 平时半睁眼像没睡醒，关键时刻眼睛微微睁开——嘴角挂着不变的笑，眼神让对面脊背发凉 |
| **行为逻辑** | 务实——选最省力路径 | 所有选择做成本收益分析 | 懒得跟人正面冲突，不是因为好欺负，而是因为早算完了——"打起来太麻烦，让他自己走到坑里更省力" |

> **融合铁律**：副标签的渗透不能覆盖主标签的底色。读者在任何场景下都能认出"这还是那个慵懒的人"——只是这个场景下他多了一层腹黑的纹理。

##### 常见多标签组合及化学反应

| 标签组合 | 化学反应 | 适合角色类型 |
|---------|---------|------------|
| 慵懒 + 腹黑 | 表面漫不经心，实则一切在掌控中 | 幕后智者、隐藏实力者 |
| 热血 + 天然呆 | 冲劲十足但方向常跑偏，却意外撞到正确答案 | 成长型主角、搞笑担当 |
| 傲娇 + 温柔 | 嘴硬心软——越在乎越说不出好话，温柔只在行动里 | 恋爱线角色、傲娇导师 |
| 沉稳 + 偏执 | 平时最可靠的人，在特定事上最不可理喻 | 有创伤的强者、复仇者 |
| 毒舌 + 护短 | 对外人尖酸刻薄，对自己人无条件维护 | 团队毒舌担当、反差萌角色 |

> **矛盾的标签如何处理**：如果两个标签存在本质矛盾（如"热血冲动"+"腹黑算计"），不要强行融合——这恰好是**反差设计**的来源（见阶段C 反差设计五维度）。矛盾的标签在不同情境下轮流主导，比强行融合更真实。

#### 行为塑造速查：以"慵懒大姐姐"为例

将四个维度合在一起看，一个完整的"慵懒大姐姐"形象在写作中可以这样落地：

| 维度 | 具体表现 |
|------|---------|
| **动作** | 打哈欠、伸懒腰、半趴在桌上、递东西时只伸一只手、走路不疾不徐 |
| **语言** | "太麻烦了……行吧"（边说边动手）、"打扰我的清闲了"、语速慢但出手不慢 |
| **神态** | 半睁眼、遇事叹气再微笑、笑起来眼睛弯成线、认真的瞬间眼神变得锐利 |
| **行为逻辑** | 务实主义——选择最省力的路径不是因为懒，而是因为聪明；口头嫌麻烦但内心信条是"能帮就帮"；底线被触时比任何人都可靠 |

> 写作时交替使用这四个维度，而不是每次都用全部四个——一章中分散嵌入几次动作+一次标志性神态+关键时刻的行为逻辑展现，角色自然活起来。

### 阶段D：人物弧光 — 信念如何在故事中生长

人物弧光不是角色"变强了"或"变厉害了"——那是能力升级，不是弧光。弧光是角色内心信念的演变轨迹。

但**演变不等于颠覆**。不是每个角色都需要从"我错了"走到"原来如此"。信念在故事中有三种生长方式：

| 弧光类型 | 信念轨迹 | 适合 |
|---------|---------|------|
| **转变型** | 旧信念被证明不完整或错误 → 形成新信念 | 成长型主角、被救赎的反派 |
| **坚持型** | 信念反复遭受考验 → 被坚持下来，因坚持而更有重量 | 信仰型主角、侠客、革命者 |
| **完善型** | 信念本身没问题 → 但最初的版本太简单，在挫折中被打磨得更成熟、更具体 | 大多数配角和部分主角 |

#### 步骤二：定义核心信念

无论哪种弧光，第一步都是明确角色的**核心信念**——驱动其行为的根本认知。这不是"谎言"，而是角色基于过往经历形成的真实认知：

- "他认为什么是对的/必须的/唯一的？"
- **这个信念是怎么形成的？**（必须有具体过往事件作为成因——而非凭空设定）
- 例："只有变得足够强，才能保护所有人"（成因：幼年因弱小目睹亲人被杀）
- 例："规则就是用来打破的"（成因：曾被僵化的规则害死过重要的人）
- 例："人本质上都是自私的"（成因：曾被最信任的人背叛）

> **好的信念不一定极端。** "只要够勤奋就能追平天赋"——在遇到真正的天才后信念遭受冲击。这种日常感的信念比"我必须毁灭世界"更容易让读者共鸣。

#### 步骤三：设计弧光路径

根据选择的弧光类型，设计信念的生长路径：

**A. 转变型弧光**：信念被冲击 → 动摇 → 推翻 → 建立新信念

- 哪些事件让角色对旧信念产生怀疑？
- 他在"坚守旧信念"和"接受新认知"之间如何反复纠结？
- 高潮时刻的关键抉择：做出与开篇**不同**的选择
  - 开篇"独自承担一切"→ 结局"信任伙伴、交出后背"
  - 开篇"隐藏实力以自保"→ 结局"公开实力以守护"
- 转变不是否定过去的自己——旧信念曾保护过他，只是现在不再适用

**B. 坚持型弧光**：信念被考验 → 承受代价 → 信念不变，但因坚持而更有分量

- 世界和处境不断向他的信念施压——失败了、吃亏了、被质疑了
- **不是考验他"会不会动摇"，而是考验他"敢不敢继续信"**
- 关键问题不是"他的信念变了吗"，而是：
  - "他为这个信念付出了什么代价？"
  - "付出代价之后，他为什么还选择信？"
  - "同样一句话，开篇说和结局再说，分量有什么不同？"
- 例：路飞自始至终相信"自由"和"伙伴"，他没有变——但经历了失去艾斯之后，这个信念的重量完全不同了
- 例：一个始终相信"善有善报"的角色，在经历了恩将仇报后，依然选择善良——不是因为天真，而是因为"如果连我都不做了，这个世界就真的没有善意了"

**C. 完善型弧光**：信念方向正确 → 但理解过于简单 → 在现实中碰壁 → 变得更成熟、更具体

- 初始信念本身没有错，但过于理想化或简化：
  - "我要保护所有人" → 碰壁后 → "我要保护那些我能保护的人，并学会承受那些我保护不了的"
  - "努力就一定有回报" → 碰壁后 → "努力不一定有回报，但不努力连可能性都没有"
  - "好人应该原谅别人" → 碰壁后 → "原谅是选择，不是义务；有些事可以不恨，但不能原谅"
- 关键：**信念的核心方向不变，但细节被生活的复杂性填充了**
- 完善型弧光更适合大多数配角——他们不需要被"颠覆"，但需要被"展开"

#### 步骤四：弧光与剧情阶段映射

对照以下三阶段框架，标注信念生长节点：

| 阶段 | 转变型 | 坚持型 | 完善型 |
|------|--------|--------|--------|
| **阶段一（初始）** | 旧信念支配行为 | 信念是力量来源 | 信念简单而坚定 |
| **阶段二（卷入→成长）** | 事件冲击旧信念，反复纠结 | 信念被世界施压，第一次尝到坚持的代价 | 现实让简单信念碰壁，开始困惑 |
| **阶段三（觉悟）** | 关键时刻做出与开篇不同的选择 | 承受代价后依然选择相信——信念的分量变了 | 接受复杂性的同时，保住了信念的核心 |

> **关联检查**：弧光路径中的关键冲击事件是否已在大纲中体现？如果没有——在大纲中标注对应的弧光节点。

---

### 阶段E：能力与限制

- "他擅长什么？不擅长什么？"
- "他的弱点是什么？（能力上的 + 性格上的）"
- "他的不可替代性在哪里？为什么这个故事需要他？"
- **关联检查**：能力和等级是否在战力体系的约束之内？特殊能力是否符合世界规则？

---

### 阶段F：情感锚点 — 读者为什么记住他

**至少满足以下四个维度中的两个**：

**① 共鸣感**（在他身上看到自己）
- 他的困境是否让读者感同身受？（被误会却解释不清、努力了没有结果……）
- 他在困境中的反应是否像一个"正常人"？

**② 崇拜感**（他做到了读者想做但做不到的事）
- 他有什么让读者觉得"太帅了"的时刻？高光是否来自自身特质而非外挂？

**③ 心疼感**（让读者产生保护欲）
- 他有没有经历过"太不容易了"的事情？注意：心疼 ≠ 卖惨

**④ 强烈印象**（一个让读者忘不掉的标签或行为）
- 他有没有极具辨识度的习惯/口头禅/标志性动作？

**反面检查**：
- "删掉这个人，故事还能成立吗？" → 不能 → 有不可替代性
- "读者一个月后怎么描述这个人物？" → 不能只是"主角的朋友"

---

### 阶段G：名场面预设 — 预制情感爆点

为每个主要人物预设1-2个能在读者心中引爆情绪的"名场面"。这些是短期的情感爆点，是让读者追读、讨论和二次创作的素材。

**四种经典名场面类型**：

**① 战损时的脆弱**
- 强大角色受伤后，流露出依赖他人的一面
- 例：主角为保护某人而魔力耗尽，病床上坦承"其实我也很怕"
- 关键：反差感——越强的人展现脆弱，越有冲击力

**② 不经意间的极致温柔**
- 冷漠/毒舌/腹黑的角色，为一个不起眼的小事或人物，展现出极致的温柔
- 例：日常毒舌的搭档，在主角发烧时默默抱来全部被子，人走了才轻声说"从小到大，只有我能欺负你"
- 关键：温柔藏在行动里，不是嘴上说

**③ 吃醋/占有欲瞬间**
- 平时冷静理性的角色，突然表现出不讲理的占有欲
- 例：一向大方的女主，看到男主和别的女生说话，面无表情地插到两人中间
- 关键：不能频繁使用——一次就够，多了变油腻

**④ 信念的宣誓**
- 在绝望的境地，角色说出贯穿全篇的核心台词
- 例：被所有人质疑时，主角平静地说"我不是来证明什么的，我只是来做一个了结"
- 关键：这句台词在前文中已经通过角色的行为让读者有所感知，说出来时是**引爆**而非**说明**

> 每种类型预设一个场景、一句话或一个画面即可。这些名场面要分散在不同章节中，不能集中投放。

---

### 阶段H：人物关系图谱

孤立的人物在故事中没有意义——人物通过关系互相定义。

#### 核心关系定义
- "这个人物与**主角**的关系是什么？（同盟/敌对/亦敌亦友/引导者/追随者/……）"
- "这个人物与**其他主要人物**的关系是什么？"
- "这些关系在故事进程中会发生变化吗？转变的触发事件是什么？"

#### 团队配置模板（如果有主角团）

**三人铁三角**（最小稳定结构）：
```
主角（行动派/热血）←→ 对手/搭档（冷静/策略派）←→ 协调者（治愈/粘合剂）
```
- 核心法则：主角与对手形成**对比和镜像**——价值观对立但能力相当。协调者提供情感支点。
- 例：鸣人（热血）+ 佐助（冷静/对手）+ 小樱（协调者）+ 卡卡西（导师）

**五色战队**（更丰富的团队模板）：

| 位置 | 性格标签 | 在团队中的作用 |
|------|---------|-------------|
| **红** | 热血、冲动、行动派 | 通常为第一主角，驱动团队前进 |
| **蓝** | 冷静、智力担当、内敛 | 红的热血搭档/对手，提供策略 |
| **黄** | 开朗、活泼、乐天 | 团队粘合剂或搞笑担当，化解紧张 |
| **绿/粉** | 温柔、治愈、包容 | 团队和事佬，情感缓冲 |
| **黑/紫** | 神秘、强大、亦正亦邪 | 后期加入的变数，增加深度和悬念 |

> **核心原则**：每个成员都从不同角度**镜像或挑战主角的核心信念**。如果主角信奉"凡事靠自己"，就配一个信奉"人必须互相依靠"的搭档——通过对比映照彼此的价值观。

#### 关系简图
```
主角 ←→ 导师（引导+情感羁绊）
主角 ←→ 挚友（互相扶持，后期有裂痕）
主角 ←→ 反派A（宿敌，但互相尊重）
反派A ←→ 导师（有旧怨，剧情伏笔）
```

---

### 阶段I：如果是反派

- "他让读者痛恨的根源是什么？"（不是纯粹的恶，是"可以理解但不可原谅"）
- "他有没有让读者觉得'可惜了'的地方？"
- 最好的反派与主角形成**镜像**——他们可能追求类似的目标，但选择了截然相反的道路

**输出文件**：`角色/{名字}-主要人物.md`

## 类型二：临时人物

**适用范围**：参与一小段剧情但戏份重要，有鲜明特色和高光时刻。

**与主要人物的区别**：不需要完整弧光，在有限篇幅内让读者记住即可。

**启发式提问：**

### 功能性定位
- "这个人物在这个剧情段中扮演什么角色？"
- "他出场的主要目的是什么？"

### 压缩版的标签组合与反差

临时人物在有限篇幅内要被记住，**反差是最有效的工具**——参考主要人物阶段B和C的方法，但只取一个最强的反差点：

- **"如果只能用一句话让读者记住他，那是什么？"**
  - "一个说话结巴但剑法行云流水的剑客" —— 一个反差就够了
  - "一个肥头大耳的油腻商人，但算账时眼神锐利得像换了个人"
- "他的特色如何在这个剧情段中**推动剧情**？"
  - 特色不能只做装饰，必须是剧情的关键因素
  - 结巴让他关键时刻说不出口→导致误会→推动冲突

### 高光时刻
- "他在这段剧情中的高光是什么？"
- "高光之后他如何离场？"
- **注意**：高光不应盖过主要人物。其高光服务于该段剧情，不是抢主角风头。

### 有限篇幅下的塑造技巧
- 一个动作/习惯代替长篇描述（每次说话前先擦眼镜）
- 一句口头禅建立辨识度
- 与不同角色的互动差异展现性格
- 告诉他一个秘密，让他为保守秘密做出选择 → 读者记住他

**输出文件**：`角色/{名字}-临时人物.md`

## 类型三：龙套

**适用范围**：有名字、会出场、参与极少剧情的角色。不是纯粹的路人背景板——他们有名有姓，在剧情中承担了具体的（哪怕是很小的）功能。

**与临时人物的区别**：临时人物在一小段剧情中有戏份和高光，需要让读者记住；龙套的剧情参与更浅——可能只出场一次、说几句话、做一件事，但这件事对推进剧情有意义。龙套只需要让读者"知道有这么个人"，不需要记住。

**与纯粹路人的区别**：纯粹路人不需要设计（"街上的行人""店里的食客"），正文中一笔带过即可。龙套比路人高一级——他们有名字，参与了极少的剧情。

### 基本要素

- **必须有名字**：龙套不是"一个满脸横肉的壮汉"，而是"王铁柱，码头的搬运工"。名字让龙套从背景中区分出来，也让读者知道"这个人后面可能还会出现"。
- **出场场景明确**：他在哪一章/哪个场景出场？
- **剧情功能明确**：他做的这件小事对剧情有什么作用？（传递信息 / 提供物品 / 引出对话 / 展示世界观细节 / 作为某个势力的代表露面）

### 启发式提问

- "这个龙套叫什么名字？"
- "他在哪个场景出场？为什么需要他出现在这里？"
- "他参与的那一小段剧情是什么？对推进故事有什么作用？"
- "他有没有一个简单的特征让人知道'有这么个人'？（一个就够了，不需要反差设计）"
- "他后面还会再出现吗？如果会，大概在什么位置？"

### 输出格式

**每个龙套独立建文件**：`角色/{名字}-龙套.md`，格式如下：

```
# {名字} — 龙套

- **出场场景**：第X章 {场景描述}
- **剧情功能**：{传递信息 / 提供物品 / 引出对话 / 展示世界观 / 势力代表露面}
- **一句话特征**：{一个简单识别特征，不需要反差设计}
- **是否再出场**：{否 / 第Y章可能}
```

**批量龙套**：如果一个事件中有多个龙套，除了各自建文件外，可在 `角色/` 下额外创建 `{事件名}-龙套速记.md` 汇总表（格式同上，用表格），方便写作时快速查阅，不必来回切换文件。

### 升级条件

如果龙套后续反复出现，或剧情功能超出了"只做一件事"的范围——**升级为临时人物**，按类型二的格式创建独立角色文件。

### 弧光类型选择指南

选择弧光类型时自问：

```
这个角色的核心信念在故事结束时...
├─ 被推翻了 → 转变型弧光
│   适合：成长型主角、被救赎的反派
│   检查：他的旧信念来自什么经历？新信念为什么更好？
│
├─ 从未动摇，但因承受代价而更有分量 → 坚持型弧光
│   适合：信仰型主角、侠客、革命者
│   检查：他付出了什么代价？代价之后为什么还选择信？
│
└─ 方向没错但最初太简单 → 完善型弧光
    适合：大多数配角、部分主角
    检查：简单信念在哪碰壁？碰壁后保留了什么、修正了什么？
```

## 常见错误

| 错误 | 为什么错 | 正确做法 |
|------|---------|---------|
| 属性标签堆砌超过8个 | 读者记不住——辨识度来自精选标签的化学反应，不是数量 | 3-5个高辨识度标签，标签之间要有化学反应 |
| 把弧光写成"变厉害了" | 能力升级≠弧光——从筑基到金丹是升级，不是角色成长 | 弧光是信念的演变轨迹，能力升级是外在表现 |
| 所有人物都是同一种弧光类型 | 配角不需要"被颠覆"，坚持型和完善型更适合大多数配角 | 先判断弧光类型，再设计路径 |
| 反派只有"纯粹的恶" | 最好的反派与主角形成镜像——追求相似目标但选不同道路 | 写出反派"可以理解但不可原谅"的部分 |
| 外貌只有标签没有具体特征 | "黑长直+赤瞳"是视觉标签，不是外貌——读者无法在脑中形成面孔 | 设计2-3个具体面部特征（脸型/眼型/特殊标记）+ 身体特征（体型/体态/体表标记），让读者能"看见"这个人 |
| 服饰与性格脱节 | 贵族千金穿得像个街头流浪者，但没有解释原因——读者困惑或出戏 | 服饰从身份层→性格层→处境层三层推导，每个穿着细节都要有来源 |
| 人物只有性格标签没有行为塑造 | 性格标签告诉读者"这是什么人"，但没有行为塑造，写作者不知道"这个人该怎么做"——性格停留在概念层面，无法落地为文字 | 为主要人物定义动作、语言、神态、行为逻辑四个维度的具体表现 |
| 多标签人物被写成"切换人格" | 平时A性格，触发后完全变成B性格——像两个不同的人共用一个身体 | 主标签始终保持底色，副标签只在上面渗透纹理——读者在任何场景都能认出"这还是同一个人" |
| 临时人物有完整背景故事 | 临时人物篇幅有限，背景故事挤占核心剧情的展示空间 | 一个强反差点+一个高光时刻就够了 |
| 龙套没有名字 | 纯粹路人不需要设计，龙套是有名字的角色——没名字说明还没想清楚这个角色存在的意义 | 龙套必须有名字，哪怕只出场一次。名字=这个角色被正式纳入故事体系 |
| 龙套出现的合理性没检查 | 穷乡僻壤的村民精通王都秘闻→世界观崩塌 | 每个龙套的出现要有合理性和剧情服务性，出场场景和剧情功能必须明确 |
| 名场面预设在结局"等着" | 名场面是短期的情绪爆点，让读者追读——全放结局没人能读到 | 分散在不同章节中，不能集中投放 |

## 危险信号 — 停下重新检查

- 角色自测三问中一问都答不出具体答案 —— 这个角色没有独立的灵魂，只是剧情工具
- 核心信念的成因是"因为他是这样的人" —— 循环论证，信念必须有具体过往事件作为成因
- 所有角色的反差点都来自同一维度（如全是"外表vs能力"） —— 重复会让反差的效力递减
- "删掉这个角色，故事还能成立吗？" → 能 —— 这个角色没有不可替代性，需要考虑是否合并或删除
- 弧光类型选了转变型，但找不到具体冲击信念的事件 —— 转变缺乏动力，弧光会是空壳
- 四维行为塑造互相矛盾（行为逻辑务实但动作拖泥带水，且未在反差设计中标注） —— 角色行为缺乏一致性，读起来不像同一个人
- 外貌特征全是发色瞳色等"插画式标签"，缺乏具体面部和身体特征 —— 读者无法在脑中形成可辨认的面孔
- 多标签人物在不同场景完全切换人格（平时慵懒，触发腹黑后从动作到语言全部变样） —— 读者觉得角色"崩了"或人格分裂。主标签的底色必须始终保持

## 完成标志

- [ ] 主要人物是否明确了弧光类型（转变/坚持/完善）？信念生长是否有足够的推动事件？
- [ ] 主要人物是否至少满足两个情感锚点？
- [ ] **主要人物是否设计了至少一个反差？（外表/能力、表里不一、身份/性格……）**
- [ ] **主要人物的外貌与服饰是否已具体设计（面部特征、身体特征、服饰风格）？是否反映了性格和出身？**
- [ ] **主要人物是否定义了行为塑造四维度（动作特征、语言特征、神态特征、行为逻辑）？如有多个标签，是否完成了多标签拆解和融合？**
- [ ] **主要人物是否预置了至少1个名场面？**
- [ ] **主要人物之间的关系图谱是否已梳理？团队成员是否形成对比和镜像？**
- [ ] **人物的能力/等级是否在战力体系的约束之内？**
- [ ] **人物的出身背景是否符合世界观设定？**
- [ ] **人物的风格是否符合指南中的文风定位？**
- [ ] 临时人物是否在有限篇幅内建立了一个强反差作为识别度？
- [ ] 临时人物的高光是否推动了剧情（而非抢戏）？
- [ ] 龙套是否有名字、出场场景和剧情功能？出现是否合理？
- [ ] 角色文件夹中每个人物是否标注了类型？

### 角色自测三问（主要人物必须通过）

1. **辨识度测试**："读者向朋友安利这个角色时，脱口而出的第一个词或第一句话会是什么？"
2. **移情测试**："这个角色所承受的痛苦或追求的快乐，有哪些是我自己也曾感同身受的？"
3. **二次创作测试**："读者会不会想为这个角色写同人、画同人图、为TA吵架？他有哪些'未完待续'的空间可供读者探索？"

> 三问中至少有两问能给出肯定且具体的答案。
