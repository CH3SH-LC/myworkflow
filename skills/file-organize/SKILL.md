# 电脑整理（编号分类文件夹维护）

## 定位

维护编号分类的文件夹结构（参考 `D:\CH3SH`）。整理 `待整理` 文件夹，把散落文件归入正确分类。**只整理不删除，移动需确认。**

## 组织规范

- 顶层用 `N.类别` 编号前缀排序（`0.myself / 1.SJTU / 2.myworld / 3.research / 4.resource`…）。
- 子目录同级编号：`1.classes`、`2.organizations`…
- 每个顶层目录放 `AGENT.md` + `STRUCTURE.md` 记录结构与规则；根目录放 `CLAUDE.md` + `README.md`。
- 未归类文件先放 `待整理`，定期整理。

## 执行流程

1. **读结构**：读目标文件夹的 CLAUDE.md / STRUCTURE.md，了解现有分类与命名约定。
2. **盘点**：列出所有 `待整理` 目录内容 + 散落在根/顶层的新增文件（只读）。
3. **归类提议**：对每个待整理项给出目标路径（按编号分类规则），用清单展示，**不直接移动**。
4. **用户确认**：确认后执行 `move`；有异议的项跳过并留待整理。
5. **同步文档**：移动后更新对应目录的 STRUCTURE.md（如需）。

## 安全铁律

- **只读盘点，移动需确认**：分类提议阶段绝不执行 move。
- **绝不删除**：整理只移动，不删除任何文件。
- **不动代码库**：有 git 的项目目录不移动（避免 git 路径失效）。
- **不移动占用中的文件**：被进程占用/打开中的文件跳过并提示。

## 分类判断参考

| 内容 | 目标 |
|------|------|
| 学习/课程资料 | `1.SJTU` 或 `2.myworld/1.mystudy` |
| 想法/项目草稿 | `2.myworld/2.myideas` |
| 研究文献/论文 | `3.research` |
| 工具/素材/模板 | `4.resource` |
| 个人文件（证件照/个人文档） | `0.myself` |
